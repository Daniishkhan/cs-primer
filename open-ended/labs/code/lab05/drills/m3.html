A real meta agent reads the archive of designs scored so far and writes something new. The stand-in does it with no model, through three decisions that make it a search, not a shuffle. Where to start: a parent from the top three, since always the best is greedy hill climbing and the whole archive wastes budget on poor designs. How far to go: one knob, so the score says something about that change. Never repeat: a child already archived is redrawn.

propose(archive, rng) returns the child's knobs as a plain dict, not yet validated, and the parent's name. List the other values of the chosen knob, in the order of SPACE, before choosing. Use only the rng given, so a seed always gives the same proposals, and never touch the archive. After 100 draws the neighbours of the top three are probably used up, so later parents may be any entry. After 400 failed draws the space is full: raise RuntimeError.
