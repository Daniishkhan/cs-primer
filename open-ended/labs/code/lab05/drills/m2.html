A meta agent (the model that proposes designs) can propose nonsense, so a gate stands between its proposal and the evaluator. validate turns a dictionary into a Design or raises a ValueError naming the offending knob; in a real loop that message goes back to the proposer as the thing to fix. The archive is the search's memory: every scored design stays, even one worse than its parent, because it may carry an idea a later design needs.

validate rejects missing or extra knobs, values outside SPACE and anything that is not a dict. One trap: True == 1 in Python, so a membership test accepts samples=True; test the type first. Archive.add appends the entry, records the design's name in _names (what in reads) and raises ValueError for a design already stored. top(k) orders by score, then fewer calls, then name, so the order never depends on insertion. Do not reorder the archive itself.
