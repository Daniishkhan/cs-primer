A design is a few settings: how a question is solved (one call, or one call per step), the prompt wording, how many answers to vote over, and how many verify-and-retry rounds follow. Scoring a design means turning it into an agent and running it. Every model call is counted, because calls are the cost. The simulated model repeats its reply to a repeated call, so a call is identified by its attempt number.

majority breaks a tie towards the answer seen first, not the smallest, so the result does not depend on the size of the numbers. build_agent returns forward(expr, model), the vote-then-verify loop of its docstring, built on the given solve_once. Give each sample its own attempt number: two samples with the same number are one answer twice, and a vote over copies fixes nothing. evaluate uses one Model for all questions and reads its calls counter: calls per question, verifications included.
