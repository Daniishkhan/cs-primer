Data that influenced a decision cannot be used to evaluate that decision. The search used its questions to decide what to keep, so its scores are biased for every survivor. A second set, the selection set, chooses the winner among a few finalists. A third, the test set, touches no decision and is scored once, at the end, to report.

three_way_split shuffles a copy of the pool with random.Random(seed) first: the pool cycles through difficulty levels, so unshuffled cuts differ in mix. The test set goes in the given SealedSet, which opens once. choose_winner re-scores (with evaluate) only the shortlist best entries by search score, because every design scored on the selection set is another chance for luck to win there. Ties go to fewer calls, then to the name. final_report opens the sealed set once, scores the winner, and returns the dict of its docstring; the inflation is the search score minus the test score.

pool of 12, sizes (5, 4, 3), shuffled:
search = items 0 to 4, selection = items 5 to 8, test = items 9 to 11
