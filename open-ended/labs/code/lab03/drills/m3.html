Random edits to program text are almost always broken: change one character and you get a syntax error or a missing name. An edit on the syntax tree cannot be: pick one node of some kind, change one thing about it, and unparse. The tree holds only legal nodes, so the text is always legal.

An edit takes (tree, rng), changes the tree in place and returns whether it had anything to edit. edit_constant collects the numeric ast.Constant nodes (int or float, not True), picks one with rng.choice, then a nudge from -2, -1, 1, 2 with a second rng.choice, never going below 0. edit_operator picks one + - * or one < <= > >= and swaps it for a different one of its family. mutate tries up to attempts times: parse, pick an edit from EDITS (read it at call time), apply, unparse. Keep the first child that differs from canonical(src) and passes is_valid, else return canonical(src).
