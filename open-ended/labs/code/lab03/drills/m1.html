Candidate programs are text nobody has read, so check before running. Parse it into a syntax tree with ast.parse and refuse any node type not on a whitelist (a list of what is allowed). A blacklist (a list of what is forbidden) always misses something: ().__class__ reaches every class with no import, but Attribute is not on the whitelist. Fuel bounds what does run: a tick at the start of the function and each loop body, until the budget is gone.

validate checks node types against ALLOWED_NODES, then the rules a type list cannot express, and raises Rejected(reason) naming the rule. instrument applies the given _Instrument transformer to a deep copy, then ast.fix_missing_locations; it also makes integers floats, because integers never overflow and a squaring loop would build a huge one. compile_restricted validates, instruments, compiles and execs into a dict whose __builtins__ holds only abs, min, max, with _tick bound to fuel.tick.
