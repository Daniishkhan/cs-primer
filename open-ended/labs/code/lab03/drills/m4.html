A database that always shows the mutation operator the single best program collapses onto one family of solutions. So programs are grouped by what they do. A cluster is the set of programs with the same signature, here the tuple of bin counts on the training instances. A cluster keeps only its shortest few distinct programs (ties by text), which fights bloat. Parents come from a two-stage draw: a cluster, then a program in it.

softmax_weights(values, temperature) gives probabilities proportional to exp(value / temperature). Subtract the maximum first, or values near -1000 all underflow to 0. A small temperature piles weight on the best; a huge one is uniform. Island.add ignores any outcome that is not ok, files the program under outcome.bins, and drops the lowest-fitness cluster (the earliest created on a tie) when there are too many. Island.sample draws a cluster by fitness, then a program within it favouring short ones, k times, and returns the distinct programs, worst cluster first.
