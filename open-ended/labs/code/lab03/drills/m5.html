A single pool of programs can still be taken over: if one family of ideas leads early, it is sampled most, and the others never mature. So the database keeps several islands, sub-populations that never see each other's programs. An island that finds nothing wastes calls, though, so every so often the weakest half is replaced. Effort drifts towards what works without collapsing to one lineage.

Database.best() returns the best program over all islands as (program, fitness), the lowest island index on a tie; Island.best() already gives one island's. reseed(rng) ranks the islands by the fitness of their best program (best first, ties by lower index) and replaces the weakest len // 2. Each replaced island becomes fresh_from_best() of a surviving island, chosen with rng.choice over the survivors in rank order. Survivors are untouched, so the best program is never lost.
