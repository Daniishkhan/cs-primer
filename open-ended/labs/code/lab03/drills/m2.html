A candidate is scored by online bin packing: items arrive one at a time, and each goes into a bin of capacity 100 at once. An evaluation must be total: every input, including a crash, an endless loop or a nonsense return value, maps to some result, because one escaped exception would lose a long search. So the result is an Outcome with a status, and a score only when the status is ok.

pack(items, priority) asks priority(item, rem) of every bin with rem >= item, uses the highest (ties to the earliest bin), opens a new bin if none fits, and returns the bin count. evaluate makes one Fuel for the whole call, shared by all instances. Wrap the compiled function in a checker that passes floats and raises unless the value is a finite int or float (type(v) in (int, float) excludes bool). Catch Rejected, OutOfFuel, the checker's complaint and any other exception separately.
