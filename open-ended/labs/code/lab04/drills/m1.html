With a fixed number of model calls, each call either asks for a fresh answer (go wider) or asks for a better version of an answer you already hold (go deeper). Two fixed strategies bracket the problem: always wider, which is best-of-n sampling, and always deeper, which polishes the first answer it gets. Each is a policy, an object whose choose picks the next action.

An action is ("wider", model) or ("deeper", node_id, model). DeeperOnly has nothing to refine on its first call, so it goes wider, then refines env.best. run_search is the loop: choose, env.apply, work out the gain, observe, log a Step. The gain is how far the new score lands above the best score before this call, or 0. Pass the same rng to every choose, and stop early once the best score reaches target. coverage(p, n) is the chance that at least one of n independent answers is right, each with probability p.

coverage(0.05, 20) = 1 - 0.95**20 = 0.64
