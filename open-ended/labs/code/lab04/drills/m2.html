A search that does not know whether refining pays must find out as it spends. The evidence is the gain each kind of action has delivered: if going deeper has been improving the best answer, do more of it; if it has paid nothing, do less. That is a two-armed bandit (two options whose payouts you learn only by trying them), with wider and deeper as the arms.

shrunk_mean averages a gain list but pulls the result toward an optimistic prior, as if a few gains of 0.1 had been seen, so an arm with no data still looks worth trying. thompson_draw samples one Gaussian (bell curve) number centred on that mean, with a spread that shrinks as data arrives: exactly one rng.gauss call. choose goes wider when there are no answers; otherwise it draws for wider first, then deeper, and takes the larger (a tie goes to wider). observe files the gain in the history of the action's kind.

no gains: mean 0.1, spread 0.2 (a wide draw)
8 gains of 0.25: mean (0.2 + 2.0) / 10 = 0.22, spread 0.2 / 3 = 0.067
