One average over a few hundred runs hides what a decision needs. A search has its own measures: the solve rate (the fraction of runs whose best score reached the target within the budget), the calls to solve (the cost of getting there) and a confidence interval (a range the true average very probably lies in).

calls_to_solve takes the median number of calls, counting an unsolved run as penalty calls (by default one more than the most calls any run used), so it ranks worse than every solved run. mean_ci returns the mean and a half-width z * s / sqrt(n), where s is the sample standard deviation (divide by n - 1). evaluate_policy builds a fresh policy and Env for every seed, with random.Random(seed + 7919) for the policy, so two policies on one seed meet the same fresh answers.
