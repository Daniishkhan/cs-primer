A search needs one number for every program it tries, including broken ones. A search that crashes on its first bad program is not a search, so utility must never raise. A working program scores minus its mean bin count, so higher is better. Anything that goes wrong scores PENALTY (-1000), far below any real score, so a failing program can never win a comparison.

Compile with compile_restricted(src, Fuel(fuel_budget)): one fresh Fuel for the whole call, shared by all instances, so an endless loop ends in OutOfFuel. Wrap the compiled function in a checker that rejects any return value that is not a finite int or float. Test type(v) in (int, float): in Python True == 1, so a program returning item > 3 would run without error and mean nothing. Run pack(items, checker) on every instance, and turn every failure, whatever its kind, into PENALTY.
