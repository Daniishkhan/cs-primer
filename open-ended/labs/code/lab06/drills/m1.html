Code that scores candidate programs for speed needs a clock that reads the same on every machine and that the candidate cannot argue with. Counting executed lines is such a clock: one tick per line. Python lets you watch a program from outside. sys.settrace(f) makes the interpreter call f on events, a "call" event when a function starts and a "line" event before each line runs.

measure(fn, args, meter) needs two functions. The global trace function receives each "call" and returns a local trace function to follow that frame's lines, or None to ignore the frame. Follow only frames whose frame.f_code.co_filename is CANDIDATE, so the grader's own lines cost nothing. The local one adds a tick to meter.ticks on each "line" and returns itself, so the next line is traced too. Save sys.gettrace() first and restore it in a finally, even if the candidate raises. Return what fn returns.

A body of three statements costs exactly 3 ticks; a helper it calls twice adds its own lines twice.
