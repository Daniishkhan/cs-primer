Tree search treats every position in a game as a small bandit (a choice among slot machines): the arms are the legal moves, and the payout is eventually winning. The tree grows one iteration at a time: select a path down by UCB1, expand it with one new child, play a random game from that child (the rollout, already written), and backpropagate the result up the path.

uct_value(wins, visits, parent_visits, c) is UCB1 for one child: its win rate plus an exploration bonus, with the parent's visits in place of t. select_child takes the highest value. expand picks a random move from node.untried, removes it, attaches a new Node for it as a child and returns it. backpropagate adds one visit to the node and every ancestor. A node's wins count for the player who moved into it, so the result flips to 1 - result at each step up.

uct_value(2, 3, 4, 1) = 2/3 + sqrt(ln 4 / 3) = 1.35
a rollout won by the leaf's mover adds to wins from the leaf up: 1, 0, 1, 0
