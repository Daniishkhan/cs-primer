Tree search treats every position in a game as a small bandit (a choice among slot machines): the arms are the legal moves, and the payout is eventually winning. Each iteration selects a path down by each child's win rate plus a bonus for being little visited, expands one new child, plays a random game from it (the rollout, already written), and backpropagates the result up the path.

uct_value(wins, visits, parent_visits, c) is that score: wins / visits plus a bonus that grows with the parent's visits, shrinks with the child's, and is scaled by c. select_child takes the highest value. expand picks a random move from node.untried, removes it, attaches a new Node for it and returns it. backpropagate adds one visit to the node and every ancestor. A node's wins count for the player who moved into it, so the result flips to 1 - result at each step up.

uct_value(2, 3, 4, 1) = 2/3 + sqrt(ln 4 / 3) = 1.35
a rollout won by the leaf's mover adds to wins, leaf to root: 1, 0, 1, 0
