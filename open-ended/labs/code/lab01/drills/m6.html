A random rollout (a random game played to the end to score a position) is a weak judge. A blunder can still look good, because the opponent, also playing randomly, often misses its own winning move. A rollout that grabs a win when it can, and otherwise avoids handing the opponent one, sees the danger at once, so the search needs far fewer iterations.

smart_rollout is the given rollout with a better move choice at every ply (each move by either player). A move wins on the spot if, after game.next, the state is terminal and game.terminal_value is 1.0 (a draw is 0.5). A move is safe if no legal reply from the new state wins on the spot. Use only the game interface, so any game works, and copy rollout's bookkeeping for whose reward is returned. mcts_player(game, iters, c, rollout_fn) returns a function player(state, rng) that runs mcts and plays best_move.

only cell 2 is safe; any other move lets X win there.
