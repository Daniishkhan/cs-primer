A policy that explores at random is as likely to re-test an arm pulled a thousand times as one pulled twice. UCB1 (upper confidence bound) explores where it is ignorant: it gives every arm an optimistic score, a guess at the highest win rate the arm plausibly has, and pulls the arm with the best score. As an arm is tried, its doubt shrinks and its average takes over.

ucb_scores(counts, totals, t, c) returns one score per arm: its average reward plus a bonus c * sqrt(ln t / n). Here n is the arm's pulls, ln is math.log, t is the number of the pull being chosen (the first is 1) and c sets how adventurous to be. An arm with no pulls would divide by zero, so give it math.inf. ucb1 calls ucb_scores and returns the index of the largest score, the lowest index on a tie.

pulls 4, 2, 1; rewards 2, 1, 0; t = 8; c = 1
scores 1.221, 1.520, 1.442 -> pull arm 1
