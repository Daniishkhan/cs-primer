A bandit is a row of slot machines, called arms. Each arm pays 1 with a hidden probability and 0 otherwise, and you get a fixed number of pulls. Every pull is a choice between exploiting (the arm that looks best so far) and exploring (an arm you know little about). Regret is what that choice costs: the reward you gave up compared with pulling the best arm every time.

pseudo_regret(probs, counts) uses the true win rates probs, which a real player never sees: each arm costs its pull count times how far its rate falls below the best rate. greedy sees only counts (pulls per arm) and totals (reward per arm), so an untried arm has no average and goes first. epsilon_greedy draws one number from rng: below eps it pulls a uniformly random arm (the greedy one included), otherwise it defers to greedy. mean_regret runs the given run_bandit for each seed and averages the regret of the counts it returns.

win rates 0.30, 0.45, 0.50; pulls 10, 20, 70
regret = 10*0.20 + 20*0.05 + 70*0 = 3.0
