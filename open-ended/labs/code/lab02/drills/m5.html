An archive is only useful if you can read it. Coverage is the fraction of reachable cells that hold an elite. The QD-score is the sum of the elites' qualities: it rises when cells fill and when elites improve. The last two functions read the route that solves the maze. A stepping stone is a cell on it that the objective would have discarded, because it is farther from the goal than the start is.

coverage counts filled cells that are reachable, using the given maze.reachable() mapped through descriptor, so the denominator is right for any bins; a key outside the reachable set adds nothing. qd_score sums the first item of each archive value. solution_path finds the archive cell containing the goal and returns the path of its elite, or None if it is empty. stepping_stones returns the sorted, distinct cells on that path whose goal_distance exceeds the start's, or None if the maze is unsolved.
