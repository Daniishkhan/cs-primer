A genetic algorithm keeps a population of genomes, scores them, lets better ones breed, and repeats. Tournament selection picks k individuals at random and takes the best as a parent, so better walkers are chosen more often but even a mediocre one has a chance. Here evolve takes a scorer, a function from the final cells to one score per walker, so a different scorer can reuse the same loop.

tournament(scores, rng, k) draws k distinct indexes with rng.sample and returns the one with the highest score. objective_scorer(maze) gives each final cell minus its distance to the goal. Each generation of evolve walks every genome, updates visited and closest, stops if a walker reached the goal, and otherwise calls scorer(ends, state) once and breeds the next population with tournament and the given mutate. state is one dict kept for the whole run, so a scorer can remember things between generations.
