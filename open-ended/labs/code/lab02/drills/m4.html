Novelty search finds many behaviours but keeps no record of the best way to reach each. Quality-diversity wants many different solutions, each as good as it can be. MAP-Elites keeps at most one solution per cell of the behaviour space, the best so far, called its elite. Each step mutates the elite of a random filled cell, and the child competes only for the cell it lands in.

descriptor(cell, bins) coarsens a final cell into an archive cell, (row // bins, col // bins). quality(maze, genome) is 1 - arrival_step / len(genome): the fewer moves to get where it ends, the better. try_insert stores the genome if the cell is empty or the quality is strictly greater, and returns whether the archive changed. map_elites starts with init genomes from random_genome, then picks the parent cell with rng.choice(sorted(archive)) so runs repeat, and varies its elite with mutate. Evaluate each genome once.

never moves: quality 1.0; arrives at move 24 of 45: 1 - 24/45 = 0.47
empty cell: a poor child is kept; occupied cell: a worse child is dropped
