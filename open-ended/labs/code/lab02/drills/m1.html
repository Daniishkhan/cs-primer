A genome is a list of moves, each 0 (up), 1 (down), 2 (left) or 3 (right). A walker starts on the start cell and follows them in order; a move into a wall, or off the edge of the grid, does nothing. Its behaviour is the cell where it ends: all the scoring works on that one cell.

path(maze, genome) returns every cell visited, start included, so 45 moves give 46 cells. MOVES holds the row and column change of each move, and maze.is_open(r, c) already refuses walls and off-grid cells, so a blocked move keeps the previous cell. walk is the last cell of path. goal_distance is the straight-line distance to maze.goal. arrival_step(cells) is the index of the last move that changed the position, or 0 if the walker never moved.
