Two systems that answered the same cases are best compared case by case. Easy cases are easy for both, so the per-case difference cancels the shared difficulty, and cases where both score the same contribute zero: the information is in the disagreements.

paired_stats takes two score lists and returns the mean difference (b minus a) with two standard errors. The paired one is the standard error of the per-case differences (use mean_se). The unpaired one is √(sea² + seb²), as if the lists came from different cases. Each z, and corr, must be 0.0 rather than an error when its denominator is 0. diff_runs matches the two runs by id, never by position, so a reordered file changes nothing, and it raises ValueError when the ids differ.
