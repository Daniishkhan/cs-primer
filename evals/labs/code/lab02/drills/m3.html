A pairwise judge sees two answers to one question and says which is better, but it may favour a slot (position bias) whatever the answers say. The defence is the swap test: judge each pair in both orders and count a win only when the same answer wins twice.

swap_test takes (question, good, bad) triples and calls judge_pair(question, first, second) twice per triple, with the good answer first once and second once. The judge returns "A" when the first answer shown wins, so turn each reply into "did the good answer win?" before counting. Pairs whose verdict flips with the order are ties, worth half in swap_score. first_slot_rate counts over all 2n judgments; every other figure counts over the n pairs.

A judge that always says "A" gets good_first 1.0, good_second 0.0, no strict wins or losses and a swap_score of 0.5: a coin flip, as it deserves.
