To instrument an agent, wrap each model call, tool call and the whole request in objects with the same interface, so the agent's behaviour does not change and the spans appear as a side effect. Metadata (names, token counts, error types) is always recorded; content (messages, arguments, results) is opt-in and masked first, because it holds personal data.

redact applies three patterns in order (email, card, phone) and must be idempotent, so a mask like <CARD> must not match a pattern itself; order ids and dates stay untouched. TracedModel.complete opens a chat span, calls the inner model, then adds the token counts and finish reason, and never stores message text. trace_tools wraps each tool in a span that stores the arguments on entry and the redacted result after success. trace_request opens the root span, runs the agent inside it, and stores the redacted input and answer once the answer is known.

redact("Refund A-1042, jo@example.com, 4929 1234 5678 9010")
  -> "Refund A-1042, <EMAIL>, <CARD>"
