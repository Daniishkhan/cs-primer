A trace is the record of one request, made of spans: timed operations, each with a parent, a status and attributes. A span's duration includes its children, so the useful figure is its self time: the part they do not cover.

The tracer keeps a stack of open spans, so a new span's parent is whatever is on top. Write Tracer.span with contextlib.contextmanager: code before yield runs on entry, code after it on exit. If the block raises, mark the span ERROR, store the exception's class name, close the span and re-raise: swallowing the error would change the program, and skipping the close would corrupt the stack. In self_times, parallel children overlap, so subtract the union of their intervals (sort by start, then sweep) after clipping each child to its parent.

parent 0-90; children 10-50, 40-70, 80-120 (clipped to 90)
covered: 10-70 and 80-90 = 70 ms, so self time = 90 - 70 = 20
