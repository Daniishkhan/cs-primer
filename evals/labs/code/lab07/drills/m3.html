A tree of spans must be reduced to a few numbers before anyone can read it, and most traces must be dropped, since storing them all with their content is neither affordable nor wise. Tail sampling decides after the trace is complete, so it can keep every trace worth reading (errors, thumbs-downs, slowness) plus a small baseline.

rollup sums tokens over the chat spans (the model calls) only: the root span may carry a copy of the total, and adding it too would double the bill. keep_trace applies its rules in order and the first match wins: an error, then thumbs-down feedback, then a duration strictly above slow_ms (exactly slow_ms is not slow), then the baseline. Choose baseline traces by hashing the trace id, not by calling a random generator, so the same id gets the same answer on every collector.
