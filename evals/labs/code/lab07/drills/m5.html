A regression suite needs a grader that decides whether one run passed, and a runner that repeats each case, because one run is a single draw from its pass rate. The grader checks properties of what the agent did, the tool calls it made, next to what it said.

check_assertion returns (ok, reason). An unknown assertion type must raise ValueError, not pass, because a typo in a case file would otherwise turn a check into a no-op. The evidence must exist: with no successful lookup, "answer consistent with the tool" fails, and a refund with no known total fails the limit check. grade_case evaluates every assertion and lists every reason, and raises for a case with no assertions, which would pass every run. run_suite returns passes out of k for each case id.
