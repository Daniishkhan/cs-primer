A score such as pass^4 over 12 tasks would change on another 12 tasks, and since the trials of one task share its difficulty, the independent units are the tasks. A bootstrap therefore redraws whole tasks, each with all its trials, and recomputes the statistic each time.

bootstrap_ci takes counts, a list of (c, n) per task, and a function stat from such a list to a number. Each repetition draws len(counts) indices with rng.randrange, in that order, so the seed reproduces the checker's draws. compare_agents is paired: both agents ran the same tasks, so one set of drawn indices is applied to both lists, and each repetition records the difference of the statistic. Independent draws would pair one agent's easy tasks with the other's hard ones and inflate the interval. An agent compared with itself must give exactly (0, 0). better names a winner only when the interval excludes zero.
