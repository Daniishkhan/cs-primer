To grade an agent, look at what it changed in the world, not at what it said or which route it took: the closing message is only a claim, and the database is the evidence. So the grader compares a snapshot taken before the trial with the database after it, and works on the diff, the values that changed, each named by its path.

db_diff walks both databases together. Where both sides hold a dict, recurse and join the keys with a dot; otherwise compare the values and record (old, new), using None for a missing key. A key present with value None still differs from an absent one, so test membership, not just the value. Lists are compared whole. grade_end_state sorts the paths into missing (expected, unchanged), wrong (changed, but not to the expected pair) and unexpected (changed, though the task never mentioned it: collateral damage). Expected pairs come from JSON as lists, so compare them as tuples.

orders.A101.refund  0 -> 25   expected
orders.A102.refund  0 -> 8    unexpected: collateral damage
