A trial is one attempt by an agent at one task, and the harness around it has four jobs: give the agent a fresh world, stop it if it loops, make the run replayable, and record what happened. If trial 2 inherited the lamp that trial 1 refunded, the result would describe the order of the trials, not the agent.

run_trial builds a Shop on a deep copy of start, so start is never touched, and takes a second deep copy as before before the agent acts. It calls agent.act(shop, task, trial_rng(task["id"], trial)); the seeded generator makes a replay identical. The shop raises StepCapExceeded on a call past the cap: catch it, mark the trial capped with an empty reply, and still grade whatever state is left with grade_end_state. A capped trial never counts as passed. The shop's transcript and token counters fill in the rest of the record.

With a cap of 5, an agent that makes exactly 5 calls is allowed; a looper that tries a sixth is recorded as capped, reply empty, not passed.
