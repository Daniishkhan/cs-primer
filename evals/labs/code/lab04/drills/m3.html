An agent that succeeds at a task once may fail it next time, so each task is run n times and you ask what k attempts would look like. pass@k is the chance that at least one of k attempts succeeds, and it rises with k. pass^k is the chance that all k succeed, and it falls with k: the number that matters when a customer meets the agent once and every failure costs money.

From c successes in n trials, count the ways to draw k of the n recorded trials (comb is already imported). All k are failures in C(n−c, k) of the C(n, k) draws, and all are successes in C(c, k). So pass_at_k is 1 minus the first share and pass_hat_k is the second. Mind the argument order (n, c, k). summarise averages over tasks, not trials. never_passes lists tasks with c = 0: more often a broken task or grader than a hard task, so read those first.

c = 6 of n = 8, k = 2:  pass@2 = 1 - 1/28 = 0.964
                        pass^2 = 15/28    = 0.536
