A model that has memorised a benchmark does better on its original items than on equally hard fresh ones, so when you cannot search the training data you look at behaviour instead. For a templated benchmark, write the fresh items yourself, the same question with new numbers, and measure the accuracy gap with an interval.

gap_test gets the 0/1 results from the given correct_flags and returns both accuracies, the gap (original minus fresh) and a bootstrap interval: redraw the templates many times, recompute the gap each time and read the middle 95%. Item i of each list is the same template, so the pairs must stay together: resample template indices and average the per-template differences, each −1, 0 or +1. Pairing cancels the part of the gap that comes from easy or hard templates. leak_detected needs the whole interval above zero, so a small leak can hide in the noise. Empty or unequal lists raise ValueError.
