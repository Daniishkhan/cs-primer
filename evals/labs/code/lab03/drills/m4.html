When benchmark questions reach a model's training data, its score measures recall, not ability. If you can search a text corpus, cut each question into n-grams (runs of n consecutive words) and measure what share of them appear in a document.

overlap is that share, 0.0 if the question has no n-grams. scan_corpus tries documents in sorted name order, keeps the first with the highest overlap so ties are deterministic, and reports it only if it reaches the threshold (inclusive). canary_docs searches exactly and case-sensitively for the canary, a unique marker planted in every benchmark file, so it finds copies of the file itself. leak_metrics gives None for precision when nothing was found and for recall when the truth is empty. The blind spot: paraphrases, translations and new numbers share no long n-grams, so a clean scan proves only that no copies were found.

item "what is the fee for a deck" has five 3-grams;
document "what is the fee for a permit" shares four: overlap 0.8
