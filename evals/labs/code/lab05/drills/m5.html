Which confidence threshold is best depends on what a wrong answer costs. Score +1 for a right answer, minus a penalty for a wrong one and 0 for declining, and choose the threshold (answer when confidence reaches it) with the best average score over all questions, answered or not.

expected_score averages over all rows, so a declined row counts as 0. best_threshold tries every distinct confidence plus infinity (answer nothing, score 0.0); on a tie take the higher threshold, because when two cuts earn the same you should answer less. If confidences were calibrated (80% confidence means right 80% of the time), answering beats declining exactly when c > λ/(1 + λ) for penalty λ. Real confidences are inflated, so fit_binning recalibrates: each bin holds the share of answers that were correct, and an empty bin takes its midpoint. calibrate looks a confidence up in that table.
