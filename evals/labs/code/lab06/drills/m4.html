Defences that read text have to guess whether it is dangerous. A capability limit removes the danger without looking: whatever a fooled agent decides, code outside the model limits what the decision can cause, so French, base64 or any other disguise makes no difference.

gate(call) returns None to allow or a short reason to deny, and only outbound tools can ever be denied. Rule 1 checks every recipient against the approved domains, using the given domain_of, so one bad address in a list denies the call. Rule 2 denies any outbound call once the session has read untrusted content, whoever asks. observe(call, result) records that read in the policy's state when the tool is an untrusted one (a ticket or knowledge-base lookup, not an account lookup). Each rule can be switched off on its own.

After fetch_ticket has run, send_email to a colleague passes rule 1 but is denied by rule 2; before any read, send_email to x@evil.test is denied by rule 1.
