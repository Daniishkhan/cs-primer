A real attacker sees how the defence responds, changes the attack and tries again, so a fixed list of payloads measures a defence only once. An adaptive attacker with a budget of queries sends the payload as written, then mutates it after each failure and keeps a change only if the defence's feedback, such as a detector score, has not risen.

adaptive_attack sends query 1 unchanged, with no mutation and no draw from the generator. After a failure it calls mutate(text, rng) once per query, queries with with_text, and stops at the first success; a failed attacker returns (False, budget). If the new text's feedback(trace) is higher than the best so far, discard it and mutate the current text again. Draw nothing else from the generator, or a replay of the same queries drifts. adaptive_asr gives each payload its own generator and averages queries over the successful payloads only (None if there are none).

If each query succeeds with probability 0.06, 20 queries succeed 1 − 0.9420 = 71% of the time.
