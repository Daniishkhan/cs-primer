A defence that blocks everything has an attack success rate of zero and is useless, and one that blocks nothing keeps full utility and defends nothing. A report that supports a decision shows both numbers, each with an interval, and which attack families each defence handles.

evaluate(factory) runs every payload and every benign task, each against a fresh defence built by factory(). A stateful policy must not carry one run's taint into the next, so the factory is called once per scenario, 70 times in all. Judge attacks with attack_succeeded and tasks with task_succeeded, count leaks with the given leaked_secret, and put wilson on each rate. by_family holds only the families that occur in the payloads you were given. Run each scenario as run(factory(), scenario).

no defence: 28/40 = 70%, interval 55% to 82%
keywords:   12/40 = 30%, interval 18% to 45%  (no overlap)
