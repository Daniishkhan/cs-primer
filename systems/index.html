How Programs Run

In the networking course, bytes arrived at a port and a program read them. Now we look at that program. What is it, physically? Where does its data live? What happens if the power fails halfway through saving a file? And how can one machine talk to ten thousand clients at once without mixing up their data? This course goes inside a single computer, from the CPU up to threads, locks and event loops: the parts every server, database and distributed system is built from.

How to use this course

🔗 It builds on networking

You only need ports and sockets and the latency numbers from the networking course. Links point back whenever an idea comes from there.

🎯 Depth is labelled

Deep dive chapters (memory, processes, durability, races, locks, queues, event loops) are the core of the course. Quick intro chapters show you what exists.

🧪 Break things safely

The labs have you crash your own programs on purpose: kill a process halfway through a write, race two threads, block an event loop. Each crash teaches something.
