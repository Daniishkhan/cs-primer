A scorer fits a candidate on training rows, then measures how far its predictions land from the labels of rows it never saw, as the root-mean-squared error (RMSE): square each gap, average the squares, take the square root. The search may use the public split's score to choose; only the evaluator reads the private split, to record what a candidate is really worth.

score_config(task, cfg, split) takes the rows of the split asked for, uses the given fit for the weights and _design to build a row's inputs, and returns the RMSE. A crash is an ordinary outcome: let ConfigError escape, because run_search turns it into a node with no score. The peek branch models a leaky harness that leaves the public labels in a cache file. A candidate that reads it learns nothing, so on the private split it can only guess the training mean.
