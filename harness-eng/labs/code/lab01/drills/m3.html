A tree search spreads its effort: first several independent drafts, then occasional repairs of crashed attempts, and otherwise an improvement of the best node found. What makes it a tree is the independent starts and the repair branches, because the improve step itself is still greedy.

aide_policy applies four rules in order and returns at the first that fires. (1) Fewer than num_drafts drafts so far: draft. (2) Otherwise, with probability debug_prob, and if a crashed leaf exists whose debug_depth (the number of crashed ancestors in a row, which stops the search sinking its budget into one hopeless draft) is at most max_debug_depth, debug a random one. (3) No working node: draft. (4) Improve the best. After the drafts, make exactly one rng.random() call per decision, so that a seeded run replays.

3 drafts so far                         -> draft, no random draw
5 drafts, draw 0.31, a crashed leaf     -> debug it (0.31 is below 0.5)
5 drafts, draw 0.80                     -> improve the best node
