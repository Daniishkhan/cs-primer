A tree search spreads its effort: first several independent drafts, then occasional repairs of crashed attempts, and otherwise an improvement of the best node (candidate tried) so far. What makes it a tree is the independent starts and the repair branches, because the improve step itself is still greedy.

aide_policy is the four rules of its docstring, tried in order. A leaf is a node nobody has built on yet, so a crashed node that already has a repair is not debugged again. debug_depth counts the crashed ancestors in a row above a node, and the cap stops the search sinking its budget into one hopeless draft. After the drafts, make exactly one rng.random() call per decision, so that a seeded run replays.
