To compare two search methods fairly, run both on the same tasks and look at the difference on each task, so that task difficulty cancels. A bootstrap interval then says how far to trust the average difference: resample the differences with replacement many times, take each resample's mean, and read off the middle 95% of those means.

paired_ci(a, b, n_boot, seed) forms a[i] - b[i] and resamples those differences, so each pair stays together. A resample has as many draws as there are pairs, each picking any pair at random, so some repeat and some are missing. Use one random.Random(seed) for every resample, so the same seed gives the same interval. Return the mean difference, then the 2.5th and 97.5th percentiles of the sorted resample means, at the indices the docstring gives.

differences [0, 2], mean 1. Resamples: [0,0] [0,2] [2,0] [2,2]
resample means 0, 1, 1, 2, so the interval runs from 0 to 2
