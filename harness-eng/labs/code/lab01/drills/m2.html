A search step is one of three actions: draft a new candidate from scratch, debug one that crashed, or improve a working one with a small edit. A greedy hill-climber always builds on the best candidate so far, never looking sideways or back, and keeps failed edits in the journal (the list of every node tried, a node being a candidate with its scores).

greedy_policy(journal, rng) returns ("draft", None), ("debug", node) or ("improve", node). With no working node yet there is no best to build on: repair the most recent crashed leaf (a node with no children) if one exists, otherwise draft. Once a working node exists, always improve journal.best(), whatever has crashed since. journal.good and journal.buggy are ready-made lists; rng is unused.

node 0 crashed, node 1 (a repair of 0) crashed too  -> ("debug", node 1)
node 0 scored 2.1, node 1 scored 1.8, node 2 crashed -> ("improve", node 1)
