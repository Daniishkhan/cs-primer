A search step is one of three actions: draft a new candidate from scratch, debug one that crashed, or improve a working one with a small edit. A greedy hill-climber always builds on the best candidate so far and never looks sideways or back, and failed edits stay in the journal (the list of every node tried, a node being one candidate with its scores) instead of being deleted.

greedy_policy(journal, rng) returns ("draft", None), ("debug", node) or ("improve", node). With no working node yet there is no best to build on: repair the most recent crashed leaf (a node with no children) if one exists, otherwise draft. Once a working node exists, always improve journal.best(), whatever has crashed since. journal.good and journal.buggy are ready-made lists; rng is unused.

0 crashed, 1 repairs 0 and crashes       -> ("debug", node 1)
0 scored 2.1, 1 scored 1.8, 2 crashed    -> ("improve", node 1)
