# Unit: re-chapters

Course: **A9 Research Engineering on Small Proxies** (id `re`, folder `research-eng/`), a new course serving Artifact 1 (autoresearch-rs). Status in the catalog: building.

## Course brief
A9 is opened while building **Artifact 1, autoresearch-rs**: Karpathy's autoresearch loop (an agent edits nanochat's `train.py`, runs it for five minutes, keeps the change if the validation score improves, reverts otherwise) with the runner, sandbox and run store rewritten in Rust, extended so that every experiment also logs the gap between proxy gain and held-out gain. The course teaches the research-engineering habits that make such a loop trustworthy: the loop as a state machine with a budget, noise floors and seeds, paired tests, proxies that transfer (scaling laws, compute-optimal sizing, μP), ablation design and run tracking, a Rust runner the reader can read and change, and the write-up a lab reviewer reads first. It builds on A0 chapters 04 (reproducible experiments), 15 (statistics for experiments), 17 (compute costs), 21-22 (programs as data, running candidates safely) and A2 chapters 12 (building a GPT), 14, 16, 17, 18 (scaling laws). Sources to fetch: github.com/karpathy/autoresearch (README, program.md, train.py), github.com/karpathy/nanochat, github.com/KellerJordan/modded-nanogpt (records log), Chinchilla (arXiv 2203.15556), Tensor Programs V / μTransfer (arXiv 2203.03466), METR RE-Bench (arXiv 2411.15114) and its tasks.
