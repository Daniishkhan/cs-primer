A log you cannot re-run is only a claim, so the test of a log is whether someone holding only the log can re-run it and get the same bytes, not merely similar numbers. That works only if each record depends on nothing but its config, its seed and the order of events: no clock, no machine name.

first_difference(path_a, path_b) compares two files as bytes and returns the 1-based number of the first line that differs, or None; a shorter file differs at its first missing line. replay(path, out_path) re-executes the log into a fresh store, in file order: a run record goes back through evaluate, an experiment record through run_experiment with its logged candidate and seed count, and a kept candidate becomes the best for the records after it. It returns the comparison of the original and the copy.

original A B C, replay A X C  ->  2   (line 2 differs)
original A B,   replay A B C  ->  3   (line 3 is missing)
