A model is a point in a space with one axis per weight, so combining models is arithmetic on points. The task vector of a fine-tuned model is the displacement from its base model to it: everything the fine-tuning changed.

Models and task vectors are both lists of four flat lists of numbers. Functions that return one build new lists and never edit their inputs, because a merge that quietly edits the base corrupts every merge after it. task_vector subtracts the base from the fine-tune; add_scaled(base, vec, scale) is base + scale * vec; average_models is the elementwise mean; interpolate(a, b, t) is (1 - t) * a + t * b. vec_norm is the length over every entry. cosine(u, v) is the dot product divided by both norms (0.0 if either is zero): near 0 the edits are unrelated, near 1 they point the same way.
