A merge recipe is a list of coefficients, and its fitness is how well the merged model scores on a set of examples. Searching means proposing recipes, merging and scoring each one, and keeping the best.

search_recipe builds the task vectors (each fine-tune minus the base) from world.finetunes and world.base. It defines fitness(w) as mean_score of the model that merge_coeffs makes from coeffs_from_vector(w, mode), measured on world.search, and passes it to evolve with random.Random(seed). Start from the plain average, [1 / N_TASKS] * RECIPE_DIM[mode]: since the best candidate is never lost, it puts a floor under the result. Never touch world.hold: a search that peeks at the held-out split reports a worthless number. Return (result.x, result).

mode "layer": RECIPE_DIM["layer"] = 6 numbers, starting at [1/3] * 6
default settings: 244 scoring calls on world.search, none on world.hold
