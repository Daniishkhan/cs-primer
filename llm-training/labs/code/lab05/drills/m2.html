Adding scaled copies of each fine-tune's change to the base model combines their skills, and a coefficient says how much of each change to apply. Here a coefficient may differ per layer, so a recipe is a small table indexed by task and layer.

coeffs_from_vector(w, mode) expands a flat list w into that table: "global" has one number for everything, "task" one per task, "layer" one per task and layer. merge_coeffs builds each tensor k (one of the four lists) as base[k] plus the sum over tasks of its coefficient for that tensor's layer (LAYER_OF[k]) times tvs[t][k]. best_global_lambda merges base + lam * (sum of the task vectors) for every lam in grid, scores each with mean_score on split and keeps the earlier one on a tie. Check yourself: all zeros give the base, a 1 for one task and 0 for the others give that task's fine-tune back, and 1/3 each is the plain average.

"task" mode, w = [0.5, 1.0, 0.0] gives [[0.5, 0.5], [1.0, 1.0], [0.0, 0.0]]
