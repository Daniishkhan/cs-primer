A bandit is a machine with several arms, each paying a noisy reward; the policy is a softmax over one logit per arm. Policy-gradient learning (called REINFORCE here) moves each logit towards arms whose reward beat a baseline, the typical reward. Without one, every large reward pushes up whichever arm was sampled and buries the signal in noise.

advantages subtracts a baseline b from each reward. Leave-one-out has no bias because its b for sample i ignores sample i's own action; the batch mean includes it and shrinks the expected gradient by (B - 1)/B. policy_gradient(logits, actions, advs) averages A * grad_log_prob(logits, a) over the samples. train_bandit repeats: for each sample in turn, draw an action with sample_action and then its reward from bandit.pull(a, rng); compute advantages; add lr times the gradient to the logits.

rewards [1, 0, 0.5]   "mean" -> [0.5, -0.5, 0]
                      "loo"  -> [0.75, -0.75, 0]  (others' means 0.25, 0.75, 0.5)
