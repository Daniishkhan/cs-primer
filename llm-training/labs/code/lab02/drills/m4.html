To reuse one expensive batch for several gradient steps, each sample gets a ratio: how much likelier its action is now than when it was drawn. The clip stops rewarding a ratio above 1 + eps when the advantage A (reward minus baseline) is positive, or below 1 - eps when it is negative.

ratio works from log-probabilities. clipped_surrogate is the smaller of r * A and the same product with r forced into [1 - eps, 1 + eps]. is_clipped is true when the clipped term is strictly the smaller (no gradient passes). In ppo_gradient a clipped sample adds nothing and any other adds A * r * grad_log_prob, because the gradient of r is r times that of the log-probability; divide by the number of samples. train_bandit_ppo freezes the old logits, then takes epochs steps on one batch.

eps 0.2, r = 1.5: A = +1 scores min(1.5, 1.2) = 1.2, clipped;
                  A = -1 scores min(-1.5, -1.2) = -1.5, not clipped
