Limiting each update does not limit how far the policy drifts over many updates. A second rope keeps it near a fixed reference policy by charging each sampled action for how much likelier the policy made it than the reference did; the average charge estimates the KL divergence, a measure of how far apart two distributions are.

shaped_rewards subtracts beta * (logp - logp_ref), the log-probability gap between policy and reference, from the reward at each step, where the drift happened. kl_k3 is a one-sample estimate from rho = exp(logp_ref - logp): (rho - 1) - log(rho), never negative. train_ppo_grid starts from a copy of ref and never changes ref. Each iteration it freezes old, plays episodes, shapes the rewards, subtracts V from the returns, then for each state takes epochs passes of ppo_gradient, weighting each state by its share of the steps. V moves towards the shaped returns.

rho = 0.5: k3 = (0.5 - 1) - ln(0.5) = 0.1931
reward 1.0, logp - logp_ref = 0.4, beta 0.1: shaped reward 0.96
