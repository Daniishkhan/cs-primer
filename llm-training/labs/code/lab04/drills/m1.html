A verifiable reward is a short program that checks an answer against the truth and returns 1 or 0. The policy (the model being trained) will search for every loophole in it, so it must be exact and must never crash on junk.

parse_number returns an exact value: Fraction turns "0.1" into precisely one tenth, so no tolerance is needed. Anything that is not a number, such as the hedge "391 or 392", gives None and not an error, because a crash would stop the run while a zero teaches the policy to stop hedging. reward is 1.0 only when the parsed value equals answer. sample_index makes one call to rng.random(), and its comparison is strict, so a zero-probability index is never chosen. kl_divergence(p, q) measures how far p has moved from q; it is not symmetric.

"3.91e2", "782/2" and "0391" all parse to 391; "391 or 392" gives None
probs [0.5, 0, 0.5]: u = 0.0 gives index 0, u = 0.5 gives index 2
