Preference training learns from pairs of answers, one chosen and one rejected, with the policy itself acting as the reward model. An answer's implicit reward is how far the policy has raised its log-probability above the frozen reference's, times a strength beta; the loss pushes the chosen answer's implicit reward above the rejected one's.

implicit_rewards and dpo_margin follow that definition (the margin m is chosen minus rejected). dpo_loss averages -log sigmoid(m) over the pairs (q, w, l); with policy equal to reference every margin is 0, so the loss starts at ln 2. For a very negative margin, sigmoid underflows to 0 and its log fails, so use -m there instead. In dpo_grads, each log-probability is its logit minus the same normaliser, which cancels in the margin, so only the chosen and rejected logits get a gradient, equal and opposite, of size beta * sigmoid(-m).

policy [0.75, 0.25], reference [0.5, 0.5], beta 1, chosen 0, rejected 1:
margin ln 3 = 1.10, loss 0.288, gradient [-0.25, +0.25]
