Comparing every pair of documents is far too slow. Instead, make similar documents land in the same bucket of a hash table and compare only those that share one: cut each signature into b bands of r values, and call two documents candidates if some band is identical in both.

band_keys(sig, b, r) returns one key per band, built from the band's index and its r values. candidate_pairs builds a dict from each key to the ids holding it; every pair inside one bucket is a candidate. Why this works: a band matches with probability s^r when two documents have similarity s, and all b bands miss with probability (1 - s^r)^b, so candidate_probability is one minus that. threshold is (1/b)^(1/r), where the curve is steepest. best_bands tries every way to split num_perm into b times r and returns the nearest threshold to the target.

similarity 0.5, 14 bands of 8: 0.5^8 = 0.0039 per band
P(candidate) = 1 - (1 - 0.0039)^14 = 0.053
