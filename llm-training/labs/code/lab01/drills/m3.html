The web repeats itself, and training on the same text twice wastes compute and encourages memorising it. Two cheap defences: compare short fingerprints (hashes) of whole documents instead of their text, and delete lines that appear in many different documents.

normalise lower-cases the text and turns every run of non-alphanumeric characters into one space, so copies that differ only in capitals or punctuation get the same fingerprint: hash the normalised text, never the raw text. exact_dedupe(docs) keeps the first document for each fingerprint, in the original order, and also returns a dict from each removed id to the id it copies. line_dedupe counts the documents each distinct line appears in (a line repeated inside one document counts once) and removes lines found in more than max_docs documents. A document left with no lines stays in the list, with "".

normalise("THE  cat!") == normalise("The cat.") == "the cat"
a line in 5 documents: removed at max_docs=4, kept at max_docs=5
