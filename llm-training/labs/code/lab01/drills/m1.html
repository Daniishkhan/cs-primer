A crawled web page is mostly not the article: it also carries menus, scripts and a footer. Extraction keeps only the text a reader would call the article, one paragraph per line.

The parser _Extractor is already in the file: after you feed it the page (and close it), its out list holds text pieces and "\n" markers. Text inside nav, footer, script and similar tags is already dropped. Block tags (p, li, br) add a marker; inline tags (b, span) do not. extract(html) turns that list into clean lines: join the pieces, split at the markers, collapse each run of whitespace to one space, strip each line, drop empty lines and join the rest with "\n". Each piece was collapsed alone, so neighbouring pieces can still leave a double space.

<nav>Menu</nav><p>Hi <b>big</b> world</p><p>Bye</p>
gives "Hi big world\nBye"
