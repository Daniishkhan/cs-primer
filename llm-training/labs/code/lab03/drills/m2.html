A low-rank adapter is two thin matrices, and training needs the slope of the loss with respect to every entry of both. The output depends on them through a chain, so each gradient is an outer product: a column times a row, which makes a matrix.

g is the gradient of the loss with respect to the layer's output for one sample (mse_grad_out supplies it). In lora_grads, both gradients carry the scale s = alpha / r. dB pairs g with the squeezed input A x; dA pairs g pulled back through B (B^T g) with the input x. So while B = 0, dA is exactly zero and only dB moves. batch_loss_and_grads runs lora_forward on each pair, takes mse_loss over all of them and sums the per-sample gradients; the 1/N of the mean is already inside mse_grad_out.

A = [[1, 2]], B = [[3], [4]], x = (1, 1), g = (1, -1), s = alpha / r = 2
dB = [[6], [-6]]    dA = [[-2, -2]]
