Training needs the slope of the loss with respect to every entry of both thin matrices. The output depends on them through a chain, input to squeezed input to expanded output, so each gradient is an outer product: a column times a row, which makes a matrix.

g is the gradient of the loss with respect to the layer's output for one sample, which mse_grad_out supplies. Read the two products in the docstring of lora_grads like this: dB is the output gradient meeting the squeezed input; dA is the output gradient pulled back through B, then meeting the input. So while B = 0, dA is exactly zero and only dB moves. batch_loss_and_grads runs lora_forward on each pair, takes mse_loss over all of them and sums the per-sample gradients; the 1/N of the mean is already inside mse_grad_out.
