A low-rank adapter freezes a layer's pretrained weights and learns the change as a product of two thin matrices: one squeezes the input down to r numbers (the rank), the other expands them back. The output is the frozen output plus a scaled correction.

count_full is d_out * d_in; count_lora counts the entries of A (r by d_in) and B (d_out by r). In init_adapter, B is zero, so the adapted layer starts equal to the pretrained one, while A is random with standard deviation 1/sqrt(d_in); with both zero, no gradient could flow. lora_forward scales by alpha / r (r is len(A)) and computes A x first, never the full product B A.

W0 = identity, A = [[1, 1]], B = [[2], [3]], x = (1, 2), alpha = 4, r = 1
h = x + 4 * B (A x) = (1, 2) + 4 * (6, 9) = (25, 38); scale alpha / r = 4
