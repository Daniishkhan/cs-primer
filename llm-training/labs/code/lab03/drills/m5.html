An experiment trains one method on the task-B data, collapses the result into one weight matrix and measures three losses: on the noisy training set, on clean held-out task-B data, and on the old task A. The last is the forgetting measure, because fine-tuning changes shared weights and nothing asks the model to keep doing task A.

evaluate(W, data) is the mean squared error of a plain matrix (use matvec and mse_loss). run_lora trains with train_lora from world.W0 on world.train_b, merges, counts parameters with count_lora and measures the merged matrix on world.train_b, world.test_b and world.task_a. run_full does the same with train_full, named "full" with fraction 1.0. Both are scored on a plain matrix, which keeps the comparison fair.

On the lab's 24 by 24 layer, rank 2 has 96 of 576 parameters (fraction 0.1667). The base model scores about 0.0002 on task A, so anything above that is damage.
