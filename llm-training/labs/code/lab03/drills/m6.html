One run is an anecdote; a sweep is a result. A practitioner wants to know the smallest adapter that gets close to the best held-out loss, and what it saves in parameters and forgetting.

sweep(world, ranks, ...) returns the full fine-tuning row first, then one LoRA row per rank in the order given, built with run_full and run_lora. verdict(rows, tolerance) takes the best test_b of any row, full fine-tuning included, and finds the first LoRA row within best * (1 + tolerance). It returns a dict: smallest_rank (the integer parsed from the row name, so "LoRA r=4" gives 4), param_fraction (that row's share of the parameters) and forgetting_saved (1 - row.task_a / full.task_a). All three are None if no LoRA row gets close enough.

test_b: full 0.10, r=1 0.30, r=2 0.105, r=4 0.12; limit 0.10 * 1.1 = 0.11
r=2 qualifies; task_a full 0.20, r=2 0.10: saved 1 - 0.10 / 0.20 = 0.5
