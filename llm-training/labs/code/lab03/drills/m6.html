One run is an anecdote; a sweep is a result. A practitioner wants to know the smallest adapter that gets close to the best held-out loss, and what it saves in parameters and forgetting.

sweep(world, ranks, ...) returns the full fine-tuning row first, then one LoRA row per rank in the order given, built with run_full and run_lora. verdict(rows, tolerance) takes the best test_b of any row, full fine-tuning included, and finds the first LoRA row within best * (1 + tolerance). Parse its integer rank from the row name ("LoRA r=4" gives 4). forgetting_saved is 1 - row.task_a / full.task_a. If no LoRA row gets close enough, all three values in the dict are None.

test_b: full 0.10, r=1 0.30, r=2 0.105, r=4 0.12: best 0.10, limit 0.11, so r=2
task_a: full 0.20, r=2 0.10: forgetting_saved = 1 - 0.10 / 0.20 = 0.5
