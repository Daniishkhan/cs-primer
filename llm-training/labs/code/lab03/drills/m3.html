Fine-tuning is a loop: run the data through, measure the loss, compute gradients, let an optimiser step. A low-rank adapter (LoRA) trains only its two small matrices with the base weights frozen, and full fine-tuning trains the whole matrix: the same loop with different parameters.

full_grads(W, data) is the full-matrix version of the last milestone: g from mse_grad_out for each sample, and dW is the sum of g x^T. train_lora makes random.Random(seed), calls init_adapter, and hands [A, B] to Adam, which edits them in place. Each step it gets the loss and gradients on all the data, records the loss before stepping, then calls opt.step. train_full does the same on a copy of W0. Neither may change W0: an in-place edit quietly spoils every later comparison.

steps = 3: losses = [loss before step 0, before step 1, before step 2]
losses[0] is the base model's loss, since B = 0 (0.3347 on the lab's data)
