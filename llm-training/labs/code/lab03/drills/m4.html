After training, the adapter is a linear correction, so it can be added into the weights: the new matrix is the old one plus the scaled product of the two thin matrices. The merged layer is an ordinary matrix that gives the same outputs as the adapter path, and subtracting the same correction restores the original.

adapter_delta builds (alpha / r) * B A with matmul. It has the full matrix shape, but it is made from r columns of B and r rows of A, so its rank is at most r however long you train. merge returns a new matrix W0 + delta and must not edit W0. unmerge returns W - delta; mat_add(P, Q, c) computes P + c * Q, so a negative c subtracts.

W0 = identity, A = [[1, 1]], B = [[2], [3]], alpha / r = 4
delta = 4 * [[2, 2], [3, 3]] = [[8, 8], [12, 12]]; merged = [[9, 8], [12, 13]]
