Some actions need a person. Rather than hold a process open while someone reads an email, write the proposal to the journal and exit: the person's decision is another event, and whichever process next picks up the run continues from it.

gate(fn, path, limit) wraps a tool and lets an amount up to the limit straight through. Above it, look in the journal for an approval with this call's key. With none, file an approval_request (never twice: asking again must not file again) and raise Paused. A decision made for different arguments is refused, because it is bound to them by digest, a short fingerprint, and to the call by its key. review answers the oldest request that has no decision, and shown is the digest the reviewer actually saw.

limit 25.00: an amount of 25.00 runs, 25.01 files a request and pauses
two identical 80.00 refunds, two keys: approving one leaves the other waiting
