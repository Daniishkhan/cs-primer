A durable agent has a failure a forgetful one lacks: a step that kills the process every time makes it resume at that step, die, resume and die again, billing you each time. The defence is an attempt counter kept in the journal, so it survives the deaths it counts.

Before running a pending call, the loop (already written) records an attempt event, and the next process finds it. attempts_for(log, seq, tool_use_id) counts the attempt events for that one call, matching both the turn and the id, minus its attempt_end events. When a tool pauses for approval, the loop writes an attempt_end first, because a step that is waiting is not a step that is failing, and a patient reviewer must not use up the attempts. When the count reaches max_attempts, the run is marked failed and goes to a human.

call (seq 1, id a): attempt, attempt, attempt, attempt_end
attempts_for -> 3 - 1 = 2
