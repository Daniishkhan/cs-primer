A tool's schema is a written contract for its arguments: their names, types, which are required and which values are allowed. The model reads it but still writes calls that break it, so the program around the model checks every call first, as it would check a web request from a stranger.

validate_args(schema, args) returns a list of problems, empty when the call is fine. The model reads each problem and acts on it, so each names the argument and says what would be valid: the allowed values, the bound crossed, an example. In Python True is an int, yet a boolean must not pass as an integer, and a pattern (a regex) must match the whole string. Registry.definitions() returns a fresh list holding, for each tool in self._tools, only name, description and input_schema: never the function.
