Routing classifies an input and sends it down a specialised path, so refunds go to the careful, expensive handler and simple tickets to a cheap one. The classifier returns a label and a confidence, and the threshold (the minimum confidence at which the router acts without a person) is a dial you set from measurement.

classify parses the reply label|confidence; a malformed reply becomes ("other", 0.0). route sends a label outside ROUTES, or a confidence below the threshold, to a human after one call; exactly at the threshold passes. evaluate_router routes labelled tickets through one meter and counts the automatic and the misrouted. pick_threshold takes the highest automatic share among rows within the error cap, ties to the higher threshold, and raises ValueError if none qualifies.

(threshold, auto, misrouted): (0.5, 90%, 20%) (0.7, 70%, 10%) (0.9, 40%, 5%)
cap 10% -> 0.7: 0.5 breaks the cap, 0.7 covers more than 0.9
