When work divides into independent pieces, run them at once and combine the results in code. Sectioning gives different checks to different calls, so the wait is the slowest one and the tokens are unchanged; voting asks several judges the same question and takes the majority, trading tokens for confidence.

section runs the checks in CHECK_SYSTEMS in order, inside meter.fan_out (in parallel) or one after another, and returns a dict of replies. majority returns the most common vote, the first seen on a tie, and raises ValueError for none. vote asks judges 0 to n-1 inside one fan_out and returns the winner and the votes in judge order. majority_accuracy(p, n) adds up the probabilities of every way that more than half of n independent judges, each right with probability p, can be right; n must be odd.

p = 0.7, n = 3: right if 2 or 3 judges are right
3 x 0.7 x 0.7 x 0.3 + 0.7 x 0.7 x 0.7 = 0.441 + 0.343 = 0.784
