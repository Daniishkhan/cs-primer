Before comparing designs you need an instrument that records every model call: tokens in, tokens out, dollars and seconds. Dollars are linear in tokens, with one price for input and another for output; seconds are a fixed overhead plus a term per token.

call_cost and call_seconds read the PRICES and LATENCY tables, already written, which are keyed by model tier, small or large. Meter.ask records a Call from the response's usage and moves the clock on. The subtle method is fan_out: work in parallel does not add up on the clock, because the slowest branch sets the wait. Here the thunks (zero-argument functions) run one after another, but each starts from the same clock reading and the clock ends at the latest finish. totals reports both seconds (the clock) and work_seconds (the sum of every call); by_step groups calls by step name.

call_cost("small", 1000, 200) = (1000*0.25 + 200*1.25) / 1e6 = $0.0005
calls of 1, 2, 3 s: in a row 6 s; in fan_out the clock moves 3 s, work 6 s
