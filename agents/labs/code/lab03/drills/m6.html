A stateless server keeps nothing between two requests: each one says who it is and what it needs, so any replica, another copy of the server, can answer it. In the 2026-07-28 revision of the protocol the handshake becomes metadata on every request.

process_modern(method, params, meta) replaces the handshake with checks on meta. The version and the client's capabilities must be present, because no earlier request told the server; a version it does not speak is reported on that request, with the supported versions in data, so the client can retry. Results carry ttlMs, how long a result may be reused, and cacheScope, public or private, as in HTTP caching, both from CACHE. Never touch self.state: one remembered fact makes two replicas answer differently. process already calls it first when _meta has either key.
