Reading is where a research system gets its evidence, so the reader returns claims: small, checkable statements, each with the exact quote that supports it, rather than a summary that has lost where each statement came from.

read_docs sends the reader exactly one user message per document, reader_prompt(question, docs[doc_id]), so it sees that page and no other, and a hostile page cannot steer how another is read. A reply that is not a JSON list puts the document in unreadable, which differs from [] (read, found nothing). Treat every item as untrusted, because the reader is a model: check that each field is present and of the right type (a bool is not an int here) and that the claim names the document that was read, and record each rejection as (doc_id, reason). Copy valid claims with ids c1, c2 and so on across all documents.
