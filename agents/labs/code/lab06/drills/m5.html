Corroboration needs independent sources: five articles that all repeat one press release are one witness, not five. So the cross-check counts origins, not documents, and reports a conflict instead of averaging it away.

origin(doc_id, docs) follows derived_from to the end of the chain; a loop, or a parent outside the document set, must end the walk, not hang it. cross_check first sets aside documents that a newer one lists in its supersedes field: their claims go to outdated and take no part. It groups the rest by (metric, year) and maps each distinct value to the sorted origins reporting it. Two or more values are a conflict, one value with two or more origins is corroborated, anything else is single_source. A conflict is reported, never voted away, with a hypothesis if a claim of a different metric equals the gap to the best value.

d8 says 4.5: conflict; a grant claim of 0.3 equals the gap, a hypothesis
