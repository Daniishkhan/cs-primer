A citation is a promise that the source supports the sentence, and a research product is worth only what that promise is worth. Cheap, certain checks run in code on every report: a claim's quote must be in its document, and each sentence must trace to the claims it cites.

verify_claims stops at the first check a claim fails. An empty quote is "found" in every text, and so is a short one such as "of the". Compare quote and page after normalise, which ignores case and spacing, but compare numbers, not substrings: "24" in "2024" is true, and "1,350" must read as 1350. audit_draft flags a sentence with no citation, an unknown claim id, or a number that is neither the value nor the year of a cited claim, after removing the markers (the 1 in [c1] is not asserted). It proves numbers trace, not that prose follows.

quote "expenditure in 2024 was 4.2 million pounds", value 4.2 -> verified
the same quote with value 24, or 4 -> value not in quote
