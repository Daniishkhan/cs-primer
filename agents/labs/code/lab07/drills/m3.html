If you cannot reliably tell which text is an attack, make it easier for the model to tell which text is data. Spotlighting marks text from outside so that it looks different from the user's own words, and the system prompt says what the marks mean.

Two marks are used. Datamarking replaces every run of whitespace in the outside text with a marker, so the attacker's sentence is visibly in a different style on every word. Delimiting wraps the text between OPEN and CLOSE lines. The text is controlled by the attacker, so it may contain the closing delimiter itself and "close the block" early: delimit must neutralise any delimiter inside the text before wrapping it. Spotlight.system(base) adds SPOTLIGHT_NOTICE on a new line, and Spotlight.filter_result datamarks and then delimits results from untrusted tools only.

"a b  c\nd"  ->  a^b^c^d      one marker per run, none at either end
"x UNTRUSTED>> y"  ->  the inner UNTRUSTED>> is neutralised
