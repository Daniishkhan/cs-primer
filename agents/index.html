Agents, Tools & Protocols

An agent is a model running in a loop, choosing tools and acting on their results. That loop is simple; making it reliable is not. This course builds it from the wire up: messages and tool calls, tool design, function calling across providers, the Model Context Protocol and agent-to-agent protocols, context engineering and memory, workflow patterns and multi-agent systems, durable execution, deep-research, computer-use and coding agents, and the security problems that come with letting a model act.

How to use this course

🔁 The simplest thing first

Most problems need a workflow, not an autonomous agent. The course teaches when each is right, and how to tell.

🔌 Protocols from the wire

You write an MCP server and client by hand, so spec changes become details rather than mysteries.

🛡️ Safe by design

Prompt injection, sandboxes and least privilege are treated as architecture, not as an afterthought.

Chapters are tagged Deep dive, Core or Quick intro so you know where to spend effort. Labs use Python's standard library and scripted stand-in models, so python3 check.py runs offline, for free, and gives the same answer every time; each lab page shows how to point it at a real model when you want to.
