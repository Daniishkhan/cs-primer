A median, a 90th percentile or a ratio has no simple formula for its wobble. The bootstrap uses computation instead: treat the sample as a stand-in for the population, redraw samples of the same size from it with replacement (some values appear twice, others not at all), compute the statistic on each redraw, and read an interval off the spread.

  • percentile reads a sorted list at position (n − 1) × q/100, blending the two neighbours.
  • bootstrap_stats redraws with the rng it is given and leaves data untouched.
  • bootstrap_interval sorts the B results and takes the middle 95%: the 2.5th and 97.5th percentiles.
  • paired_bootstrap_interval resamples question numbers, not scores, so each question keeps both systems' results. Resampling the two lists separately throws the pairing away.
a = [0 1 1 0], b = [1 1 1 0], resample questions 0 3 1 0
b - a over those questions: 1 0 0 1, so this redraw gives 0.5
