A median, a 90th percentile or a ratio has no simple formula for its wobble. The bootstrap uses computation instead. It treats the sample as a stand-in for the population and redraws samples of the same size with replacement (some values appear twice, others not at all). It computes the statistic on each redraw and reads an interval off the spread.

  • percentile(sorted_xs, q) finds the value that q% of a sorted list lies below. Between two neighbours, blend them in proportion.
  • bootstrap_stats redraws with the rng it is given and leaves data untouched.
  • bootstrap_interval sorts the B results and takes the middle 95%: the 2.5th and 97.5th percentiles.
  • paired_bootstrap_interval resamples question numbers, not scores, so each question keeps both systems' results. Two systems tend to find the same questions easy, so their difference is far less noisy than either score; resampling the lists separately would lose that.
