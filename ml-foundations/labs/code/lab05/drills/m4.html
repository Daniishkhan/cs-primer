Power is the chance that an experiment detects an effect of a given size when the effect is real. A test with 10% power says "not significant" almost every time, and the rare times it reaches significance, noise has usually inflated the estimate. That exaggeration is the winner's curse.

  • sample_size finds the n at which the true difference sits 1.96 + 0.84 standard errors from zero (1.96 for the 5% false-positive rate, 0.84 for 80% power). Round up. The effect is squared in the formula, so halving it costs about four times the users.
  • simulate_power checks the formula by experiment: draw both arms' counts with the given binomial, run two_proportion_z_test, count rejections. With p1 equal to p2 it measures the false-positive rate. If k1 + k2 is 0 or 2n there is nothing to test: count no rejection.
  • winners_curse averages the observed lift over all experiments and over the wins only.
10% to 12%: 3,839 users per arm
10% to 11%: 14,749 (half the effect, 3.8 times the users)
