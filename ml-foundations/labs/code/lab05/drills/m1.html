An average computed from a sample would come out a little different on another sample. The standard error is the typical size of that wobble, and a confidence interval is the estimate plus and minus a few standard errors: the values the data do not rule out.

  • sample_variance divides by n − 1, not n, because a sample sits closer to its own mean than to the population's.
  • std_error is the square root of that variance divided by n.
  • mean_interval goes z standard errors each side. For 95%, z is the 97.5% point of the normal curve, which the given phi_inv returns.
  • wald_interval applies the same recipe to a share k/n. It collapses to one point at k = 0 or n, and you must not repair that.
  • wilson_interval asks which true rates would make the count unsurprising, so it keeps some width and stays inside [0, 1].
