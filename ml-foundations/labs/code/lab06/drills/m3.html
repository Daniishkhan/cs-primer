A mutation is a small random change to a program. Flipping a character in the text nearly always breaks the grammar, but replacing one part of the syntax tree with another valid part never does, so the edits work on the tree.

Each edit takes (tree, rng), changes one node in place and returns True, or returns False when the tree has no node of the right kind. Collect the candidates with ast.walk, return early if there are none, then choose with rng.choice and never the global random, so one seed replays a whole run. A BinOp node keeps its operator in an op field; a Constant, Return or Assign keeps its value in value. Squaring copies the expression and grows the tree, so allow it only up to SQUARE_LIMIT nodes. An edit can change nothing or break a rule, which is why mutate retries.

return gap * 1
perturb_constant:  gap * -3
swap_operator:     gap + 1
wrap_expression:   abs(gap * 1)
