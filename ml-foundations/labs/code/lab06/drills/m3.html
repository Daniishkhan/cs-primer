A mutation is a small random change to a program. Flipping a character in the text nearly always breaks the grammar. Replacing one part of the program's syntax tree (its nested parts) with another valid part never does, so the edits work on the tree.

  • Each edit takes (tree, rng), changes one node in place and returns True, or False when the tree has no node of the right kind. Collect candidates with ast.walk, then choose with rng.choice, never the global random, so one seed replays a whole run.
  • A BinOp keeps its operator in op; a Constant, Return or Assign keeps its value in value. To build a node you have not met, such as the call abs(x), print ast.dump(ast.parse("abs(x)")) and copy its shape.
  • An edit can change nothing, give the same text or break a rule that validate checks, which is why mutate retries.
