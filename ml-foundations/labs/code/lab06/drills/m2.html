Online bin packing places items one at a time into bins that hold 100 units. A heuristic is a small function that scores one open bin for one item; the item goes to the highest score, or into a new bin if no open bin has room.

pack(priority, items) returns the number of bins used. For each item it calls priority(item, rem) once per bin whose space left rem fits, in bin order, and keeps the strictly highest score, so ties go to the earliest bin. A score that is not a finite int or float (True, nan, a string) raises ValueError. score(src, instances) returns the mean bins over the instances and must never raise: it compiles with make_heuristic (already written), packs every instance, and returns PENALTY for any failure. Fuel runs out while packing, so one try covers both steps.

items 20 30 60 20 50, bins of 100
score 0 (first fit):      [20 30 20] [60] [50]  3 bins
-(rem - item) (best fit): [20 30 50] [60 20]    2 bins
