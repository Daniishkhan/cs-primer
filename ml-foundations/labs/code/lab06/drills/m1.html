Code that nobody has read can do anything your machine can, so check it before it runs. Parse the text into a syntax tree (the program as nested parts, one node per name, number or operator). Refuse any tree with a part outside an allow-list (the node types you permit), and run what passes with almost nothing in scope.

  • validate(src) walks the ast.parse tree with ast.walk and returns it, or raises Rejected. Unparseable text, a source over MAX_CHARS and a tree over MAX_NODES nodes must raise it too.
  • make_heuristic(src, fuel) validates, passes the tree through instrument, compiles it and runs it with exec(code, namespace). The given instrument plants a _tick() call that spends one unit of fuel (a step budget), so endless loops run dry.
  • The dictionary namespace is the code's whole world. A def stores its function there. Python adds every ordinary built-in name unless the dictionary has its own __builtins__ entry.
