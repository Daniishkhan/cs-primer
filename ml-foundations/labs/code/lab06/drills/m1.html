Code that nobody has read can do anything your machine can, so check it before it runs. First turn the text into a syntax tree (the program as nested parts, one node per name, number or operator). Refuse any tree with a part that is not on an allow-list, and run what passes with almost nothing in scope.

validate(src) parses with ast.parse, tests every node from ast.walk against ALLOWED_NODES, and returns the tree or raises Rejected. Text that does not parse, a source over MAX_CHARS and a tree over MAX_NODES nodes must raise it too. make_heuristic(src, fuel) validates, passes the tree through instrument (already written: it plants a _tick() call that spends fuel), compiles it and runs it with exec(code, namespace). The dictionary namespace is the code's whole world: a def stores its function there, and Python adds every ordinary built-in name unless the dictionary has its own __builtins__ entry.

return -(rem - item)   accepted
return len(rem)        Rejected (call to len)
return item.real       Rejected (Attribute node)
