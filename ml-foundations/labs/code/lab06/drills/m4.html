Mutation repeats itself and scoring is the costly step, so each distinct program should be scored once. That needs a name that ignores layout: the hash (a short fingerprint of a text; equal texts always give equal hashes, different texts almost never) of the program's canonical form (one standard text for programs that differ only in spacing and comments).

canonical_hash(src) hashes the canonical text with hashlib.sha256 and keeps the first 12 hex digits. Archive.add(src, parent, score) returns False and stores nothing when that hash is already in entries. Otherwise it stores an Entry, appends one JSON line (one JSON object per line, so a crash loses at most the last line) to lines and, when path is not empty, to that file in append mode, then returns True. Archive.best() breaks ties by shorter source, then smaller hash, so the answer never depends on insertion order.
