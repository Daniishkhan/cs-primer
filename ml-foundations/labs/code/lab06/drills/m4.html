Mutation repeats itself and scoring is the costly step, so each distinct program should be scored once. That needs a name that ignores layout: the hash of a canonical form. A canonical form is one standard text for programs that differ only in spacing and comments. A hash is a short fingerprint of a text: equal texts give equal hashes, different texts almost never.

  • canonical_hash(src) hashes ast.unparse(ast.parse(src)), since parsing drops comments and spacing. Use hashlib.sha256 and keep the first 12 hex digits.
  • Archive.add is a gate. A repeat changes nothing, in entries, lines or the file, and returns False. A new program is stored as an Entry and logged as one JSON line. JSON Lines means one JSON object per line, so a crash loses at most the last line. Each entry names its parent, so the log is a family tree.
  • Archive.best() breaks ties by shorter source, then smaller hash, so insertion order never matters.
