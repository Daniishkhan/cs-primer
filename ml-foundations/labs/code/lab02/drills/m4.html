Gradient descent moves every parameter a small step against its gradient, the direction that lowers the loss. Each round runs in a fixed order: zero the gradients, compute the loss from the current parameters (the forward pass), run backward(), then update.

  • The order is the lesson. Every _backward adds with +=, so the last step's gradients are still in .grad. Without zero_grad, each update uses the sum of all gradients so far.
  • sgd_step changes data, never grad. mse_loss is built from Values, so it stays differentiable. Its targets are plain numbers, and mismatched or empty inputs raise ValueError.
  • train returns the loss recorded before each update, one entry per step. loss_fn takes no arguments and returns a Value.

step 1: grad -6.0, w = 0.6
step 2: grad -4.8, w = 1.08  (without zero_grad: grad -10.8, w = 1.68)
