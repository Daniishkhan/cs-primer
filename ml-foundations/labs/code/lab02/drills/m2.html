Reverse mode starts at the output (the loss) and pushes gradient back to the numbers it was computed from. A node's gradient must be complete before it is pushed on, so nodes are visited in reverse topological order: every node comes before the nodes it was computed from.

  • topo_order(root) lists every reachable Value once, parents first and root last. A graph can be 10,000 nodes deep, past Python's recursion limit of about 1,000 frames, so search with an explicit stack, not recursion.
  • backward() sets self.grad = 1.0 (the derivative of a thing with respect to itself), then calls each node's _backward in the reverse of that order. The _backward functions of __add__ and __mul__ are already written. They use +=, because one Value can be used many times.
f = x * y + x at x = 2, y = 3: x is used twice
x.grad = 1 (through the +) + 3 (through the *) = 4;  y.grad = 2
