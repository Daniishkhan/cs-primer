A model assigns a probability to the observed data. The likelihood is that probability as a function of the model's parameter, and the maximum-likelihood estimate (MLE) is the parameter value that makes the data most probable. The likelihood of n independent observations is a product of n small probabilities, which underflows to 0, so work with its logarithm: a sum with the same maximum.

  • A term whose count is 0 contributes 0 even if its probability is 0 (0 ln 0 = 0). A positive count with probability 0 makes the data impossible, so return -math.inf.
  • gaussian_mle with ddof=0 divides by n. That runs low on average, because the residuals are measured from a mean fitted to the same data; ddof=1 divides by n − 1.
  • The answers are familiar ones: the MLE of a probability is a frequency, of a mean an average, of a Poisson rate the mean count.
