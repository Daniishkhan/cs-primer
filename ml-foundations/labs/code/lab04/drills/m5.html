A language model's last layer gives one raw score (logit) per token. The softmax turns them into probabilities, and the next token is drawn from those. Temperature T divides the logits first: below 1 the largest logits pull ahead, above 1 the distribution flattens. Top-k keeps the k most probable tokens, and top-p keeps the smallest set of most probable tokens whose probabilities add up to at least p. Both renormalise the survivors.

  • Entropy, −∑ p log p, measures how much choice is left, in bits when the logarithm has base 2. Perplexity is 2 to the power of the entropy: the effective number of equally likely options. A term with p = 0 contributes 0, which the code must say.
  • As T tends to 0 the softmax tends to the arg-max, so T = 0 is refused. At T = 0.001 the scaled logits reach the thousands, so use the given stable softmax.
p = (0.5, 0.25, 0.125, 0.125): entropy 1.75 bits, perplexity 3.36
top-k with k = 2, or top-p with p = 0.7: (2/3, 1/3, 0, 0)
