A computer's one source of randomness is a generator whose numbers behave like independent draws, uniform on [0, 1). Every other distribution is built from them. In inverse-cdf sampling, the cumulative distribution function (cdf) F(x) = P(X ≤ x) maps a value to a probability, so draw u uniformly and return the x with F(x) = u.

  • sample_categorical: the cdf of a few outcomes is a staircase of running totals, and u lands on one step with probability equal to its length.
  • box_muller: the Gaussian cdf has no closed-form inverse, so a radius from one uniform and an angle from the other give two independent Gaussians.
  • rejection_sample proposes x and a height u, and keeps x when u falls under the curve. Each try succeeds with probability 1/bound, so a spiky density is expensive.
  • The checker scripts the uniforms: make exactly the rng.random() calls each docstring states, in order.
