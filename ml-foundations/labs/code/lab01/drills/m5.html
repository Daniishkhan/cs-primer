Power iteration finds one eigenpair. To find the next, remove the first: for a symmetric matrix with eigenvalue λ and unit eigenvector v, subtracting λ v vT gives a matrix with the same eigenvectors except that v's eigenvalue is now 0. This is deflation. PCA runs it on the covariance matrix of the centred data: the eigenvectors are the directions of greatest variance, and each eigenvalue is the variance along its direction.

  • top_k_eigen works on a copy of A, so the caller's matrix is unchanged. Each pass records the pair, then deflates with the given outer.
  • reconstruct centres each row, takes its coefficient along every component, and rebuilds the row from the mean. The squared error left after k components equals the sum of the eigenvalues you dropped.
