Gram-Schmidt replaces a list of vectors by an orthonormal list (every vector of length 1, every pair perpendicular) that spans the same space. Take the vectors in order and subtract from each its projection onto every basis vector found so far. What remains is perpendicular to all of them: scale it to length 1 and add it to the basis.

  • Subtract the projections one at a time from the running remainder. The classical version projects the original vector each time and, on nearly parallel input, loses perpendicularity to rounding error.
  • If almost nothing remains, the vector depended on earlier ones. Normalising a speck of 1e-17 would invent a meaningless direction, so skip it.
  • qr records what you subtracted: R[i][j] is basis vector i dotted with column j (zero below the diagonal), and Q holds the basis vectors as columns, so Q R = A.
(3, 0), (1, 2): q1 = (1, 0); (1, 2) minus 1 * q1 is (0, 2), so q2 = (0, 1)
(1, 0), (2, 0), (0, 3): (2, 0) leaves nothing, so two vectors
