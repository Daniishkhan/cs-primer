Which optimiser wins depends on the surface, and the learning rate usually matters more than the optimiser. A fair race therefore gives each optimiser its own best rate. A real training loop then combines everything: gradient, schedule, clipping, step.

  • best_lr(make, fn, w0, grid, steps) builds a fresh optimiser with make(lr) for every rate, because an optimiser carries state. The given minimise makes skipping a diverged run cheap. Replace the best only on a strictly lower loss.
  • In train the order is the lesson: gradient, then schedule, then the given clip_by_global_norm, then step. The schedule multiplies the base rate you saved before the loop, not the current opt.lr, or it would compound. Record the rate actually used.
