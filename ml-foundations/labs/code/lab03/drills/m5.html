A good learning rate changes over a run: large early to make progress, small late so the weights settle. A schedule is a multiplier on the peak rate that depends on the step t. Gradient clipping caps the length of an occasional huge gradient, so one bad batch cannot wreck the run.

  • After its ramp, warmup_cosine lets p run from 0 to 1 over the remaining steps. (1 + cos πp)/2 falls from 1 to 0 as p does, so scale it to end at floor. With warmup = 0 there is no ramp: start at 1.0.
  • wsd (warmup, stable, decay) holds the peak, because the stable phase does not depend on the final length: a run can be extended or branched.
  • Clip by the global norm: all gradients of all parameters form one long vector. One common factor keeps the update's direction and caps its length; clipping each tensor alone would change the direction.
