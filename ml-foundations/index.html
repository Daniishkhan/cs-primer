Math & Code for Machine Learning

Every later course in this path leans on a small amount of mathematics and a habit of careful experiments. This course teaches exactly that amount, at the moment you need it, and turns each idea into code: arrays and broadcasting, vectors and matrices, the singular value decomposition, derivatives and a hand-built autograd engine, the optimisers that train every network, floating point, probability, likelihood, entropy and the statistics that tell a real improvement from noise.

How to use this course

🧮 Maths you will use

Nothing here is maths for its own sake. Every topic is introduced because a later chapter needs it, and each says which one.

🛠️ Built by hand

You write a small linear-algebra library, an autograd engine and an optimiser race before any library does it for you.

📏 Honest numbers

The statistics part teaches error bars, the bootstrap and the peeking trap: the habits every evaluation in this path depends on.

Chapters are tagged Deep dive, Core or Quick intro so you know where to spend effort. Labs use Python's standard library and scripted stand-in models, so python3 check.py runs offline, for free, and gives the same answer every time; each lab page shows how to point it at a real model when you want to.
