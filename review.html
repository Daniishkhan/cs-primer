Review

Reading a chapter once leaves you able to recognise its ideas; answering questions about it days later is what makes you able to use them. This page asks you the quiz questions from the pages you have finished, ten at a time, and brings each one back just as you are about to forget it.

How it works

Every question sits in a box. A right answer moves it up a box and spaces it further out: tomorrow, then in 3, 7, 16, 35 and 80 days. A wrong answer sends it back to box 1, so it returns tomorrow. Each session starts with the questions that are due, then adds new ones. This schedule is called a Leitner system, and it works because remembering something just before you would have forgotten it makes the memory last longer (the spacing effect).
