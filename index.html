Zero to AI Systems

How do learned models work, and how do you build systems that improve them? This path starts from school mathematics and builds one layer at a time: the maths in code, machine learning, deep learning and transformers, training language models, agents, evaluation, and search and self-improving systems. It ends in four public artifacts: small replications of published research-automation results, each with one honest extension of its own.

The artifact track → Start with A0

    How it teaches

    Every chapter explains a mechanism from first principles, with one analogy, numbers you can check and a diagram, before any library does it for you. Then you predict, simulate, build and measure:

    🧮 Read the maths

    Every formula is typeset, and the ones a chapter is built around are broken down: in words, symbol by symbol, step by step, then computed on numbers you can change.

    ▶ Run it in the page

    Chapter scripts and labs run in your browser: edit, run, and check your lab code against its checker without installing anything.

    🔬 Measure it for real

    Workbench pages predict a number from the chapter, then measure it with PyTorch and Hugging Face on the lab VM or a rented GPU.

    🔁 Keep it

    The Review page brings back the quiz questions of what you have finished, spaced so they stick.

    Labs use the standard library and scripted stand-in models, so every check is free, offline and repeatable; plug in a real model when you want to. The lab machine page sets up the rented VM every workbench runs on and, later, a GPU box. Nothing runs on your own computer except the browser.
