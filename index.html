Zero to AI Systems

How do learned models work, and how do you build systems that improve them? This path is learnt by building. It starts with five real taxi rides and a guess at the fare, and grows one program, one function at a time, into a loop that improves its own model. Every function you write is checked on real data before you move on. The courses, from school mathematics to self-improving systems, are the reference you open when a step sends you there.

Start here: the leg

A leg is one program that grows for twenty steps. Each step starts from the data, hits a wall, gives you the one idea that gets past it, and asks you to write one function. The checker runs it on 6,367 real rides and prints real numbers. A collapsed box on every step shows how PyTorch does the same thing, run on the lab machine. No reading before the first step.

    The courses

    The reference. Each chapter explains one mechanism from first principles; the steps and the drills link to the chapter that explains what they ask for, and the artifact track lists the chapters each artifact needs.

      How it teaches

      Every chapter explains a mechanism from first principles, with one analogy, numbers you can check and a diagram, before any library does it for you. Then you predict, simulate, build and measure:

      🧮 Read the maths

      Every formula is typeset, and the ones a chapter is built around are broken down: in words, symbol by symbol, step by step, then computed on numbers you can change.

      ▶ Run it in the page

      Chapter scripts and labs run in your browser: edit, run, and check your lab code against its checker without installing anything.

      🔬 Measure it for real

      Workbench pages predict a number from the chapter, then measure it with PyTorch and Hugging Face on the lab VM or a rented GPU.

      🔁 Keep it

      The Review page brings back the quiz questions of what you have finished, spaced so they stick.

      Labs use the standard library and scripted stand-in models, so every check is free, offline and repeatable; plug in a real model when you want to. The lab machine page sets up the rented VM every workbench runs on and, later, a GPU box. Nothing runs on your own computer except the browser.
