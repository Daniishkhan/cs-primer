A harness that finds leaks must also stay silent when there are none: every detector has a threshold, every threshold has false alarms, and a tool that cries wolf on clean data gets switched off. So one function runs the same four detectors on any dataset, without knowing which leak is planted, and reports each leak it finds with the numbers that prove it.

hunt(case, seed) returns {kind: evidence}, empty when nothing is found, using the detectors already written; the docstring gives each rule. Two details matter. The shuffle test must run the team's own validation, case.cv_fn, because the leak lives in the team's procedure. Contamination needs both a twin share and an AUC gap: repeated entities the model cannot exploit give a share without a gap, and noise between fold layouts gives a gap without a share. Evidence strings quote the numbers, and the case must be left unchanged.
