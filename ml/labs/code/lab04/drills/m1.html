A leak hunt rests on two measuring tools. The ROC AUC scores how well a model ranks positives above negatives (0.5 is a coin flip, 1.0 is perfect), and cross-validation scores it only on rows it was not trained on.

roc_auc works from ranks (1 is the lowest score, and tied scores share the average rank). If every positive outscored every negative the positives would hold the top ranks, and if none did the bottom ones, so the AUC is where their rank sum falls between those extremes. kfold_splits deals the rows into k folds that each take a turn as the validation set. cross_val_auc calls fit on each fold's training rows only: a model here is fit(X_train, y_train) returning predict(X), so every learned step lives inside fit and cannot see a validation row.

scores 1, 2, 2, 3, labels 0, 1, 0, 1: ranks 1, 2.5, 2.5, 4; positives sum to 6.5
extremes 1 + 2 = 3 and 3 + 4 = 7, so AUC = (6.5 - 3) / (7 - 3) = 0.875
