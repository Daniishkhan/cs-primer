Machine Learning & Data Science

Most machine-learning failures are not modelling failures: the wrong target, a metric that rewards the wrong errors, a validation split that leaks the answer, a probability nobody calibrated. This course teaches the whole data-science loop, from framing a question to proving a model helped, with linear models, trees and gradient boosting as the workhorses and leakage, calibration and honest validation as the discipline.

How to use this course

🎯 Frame before you fit

Every model starts from a decision someone will make with its output. The course keeps returning to that decision.

🌳 Workhorse models

Linear models and boosted trees still win most tabular problems. You build both from scratch, then use the libraries.

🔍 Trust the number

Cross-validation, leakage hunting and calibration get as much space as the models, because that is where projects fail.

Chapters are tagged Deep dive, Core or Quick intro so you know where to spend effort. Labs use Python's standard library and scripted stand-in models, so python3 check.py runs offline, for free, and gives the same answer every time; each lab page shows how to point it at a real model when you want to.
