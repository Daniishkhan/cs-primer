A log is evidence only if a change to it shows. In a hash chain every record stores the hash of the record before it, and its own hash covers that value, so editing, deleting, swapping or inserting any record breaks every hash after it.

append(body) adds {"i", "prev", "body", "hash"}: i is the record's position, prev is the current head (the newest hash, or GENESIS when empty) and record_hash (given) makes the hash. verify_chain(records, anchor) checks each record against the one before it and returns the first bad index, or None. A chain alone cannot catch a rewrite: an attacker who changes record 3 can recompute every hash after it. So the last hash must also equal the anchor, a head hash kept where the writer cannot reach, and a consistent log that ends elsewhere returns len(records).

six records, edit record 2: returns 2
rewrite from 2 on with every hash recomputed: None, but with the anchor: 6
