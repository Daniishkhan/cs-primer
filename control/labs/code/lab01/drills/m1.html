A result is evidence only if the reader can tell it came from the evaluator and was not edited on the way. A plain hash cannot show that, because anyone who edits the payload can recompute the hash; a keyed hash (an HMAC) can, because only a holder of the secret key can produce a valid tag.

make_envelope builds the six-field envelope: the hash is over the payload's canonical JSON (canonical and sha256_hex, given) and the signature, from _signature, covers the tool, the sequence number and that hash. It refuses a payload that fails schema_problem, leaving no room for free text. verify_envelope trusts nothing the envelope says about itself: it recomputes, compares signatures in constant time (== returns sooner the earlier two strings differ) and reports the first failing reason in the docstring's order. The sequence number defeats replay of an old, genuine result.

edit the payload: hash fails.   Edit it and re-hash: signature fails.
a genuine envelope shown at the wrong seq: only seq fails.
