Retrieval, Search & Document AI

A model can only answer from the evidence it is given. Getting the right evidence in front of it, from messy documents, with a source a reader can check, is most of the work of a useful AI system. This course covers search from BM25 to dense and hybrid retrieval, how to measure it, vector indexes, retrieval-augmented generation with verified citations, and document understanding: PDFs, layout, OCR, tables, forms and retrieving pages as images.

How to use this course

📏 Measure retrieval first

A test collection and nDCG come before any embedding model, so every later choice is decided by evidence.

🔎 Lexical still matters

BM25 is built by hand and stays in the pipeline: hybrid search beats either half alone.

📄 Real documents

Scanned forms, tables and multi-column PDFs are where systems fail, so they get a whole part.

Chapters are tagged Deep dive, Core or Quick intro so you know where to spend effort. Labs use Python's standard library and scripted stand-in models, so python3 check.py runs offline, for free, and gives the same answer every time; each lab page shows how to point it at a real model when you want to.
