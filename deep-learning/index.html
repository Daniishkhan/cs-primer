Deep Learning & Transformers

A language model is a stack of matrix multiplications trained to predict the next token. This course builds that sentence up from a single neuron: backpropagation, training dynamics, embeddings, attention, the Transformer block, a GPT written by hand, tokenisers, decoding, the arithmetic of parameters, FLOPs and memory, scaling laws, and the architectures that power today's models, including the ones that read images.

How to use this course

🧠 From a neuron to a GPT

Each part adds one idea, and by Part 3 you train a working GPT in plain Python.

📐 Count everything

Parameters, FLOPs and bytes of memory are worked out by hand, so a model card's numbers mean something to you.

🔬 Read the papers

Case studies walk through AlexNet, the Transformer, GPT-3, Chinchilla and FlashAttention from the original sources.

Chapters are tagged Deep dive, Core or Quick intro so you know where to spend effort. Labs use Python's standard library and scripted stand-in models, so python3 check.py runs offline, for free, and gives the same answer every time; each lab page shows how to point it at a real model when you want to.
