To draw a token, lay the probabilities end to end along the interval from 0 to 1; the token whose segment contains a random number u is the draw, so a token with probability 0 can never be picked. Generating text repeats this: ask the model for logits on the text so far, pick a token, append it.

sample_from returns the first token whose running total exceeds u; if rounding leaves the last total slightly below 1 and u lands in that gap, fall back to a token with non-zero probability. next_token applies temperature, top-k, top-p and min-p in that order, then draws with exactly one rng.random(), so seeded runs stay reproducible when settings change; temperature 0 means greedy and uses none. generate shows the model the whole context and returns a new list.

probabilities (0.25, 0.0, 0.75): running totals 0.25, 0.25, 1.0
u = 0.1 gives token 0; u = 0.25 gives token 2; u = 0.9 gives token 2
