Training is a loop over real pairs. Every word has two rows of numbers, an input vector (when it is the centre word; this is the one you keep) and an output vector (when it is a context word), held in two tables. For each pair, draw noise words, compute the loss and gradients, and nudge only the few rows involved.

The output table starts at zero and the input table small and random. That is safe: the gradient on an input vector is built from output vectors and the other way round, so the random input rows make the output rows learn from the first step. Compute all gradients before changing any row, because each uses the others' old values; a noise word drawn twice is updated twice. Use cumulative, sample_negatives, sgns_loss and sgns_grads, and only the rng made from seed.

k = 5: a model that knows nothing scores (5 + 1) ln 2 = 4.159 per pair
one step touches 1 + 1 + 5 = 7 rows, however large the vocabulary
