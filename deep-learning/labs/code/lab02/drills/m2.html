Scoring a centre word against every word in the vocabulary is far too slow. Negative sampling asks a few yes-or-no questions instead: for each real pair, draw k random noise words, and teach the model that the real pair is real and the noise pairs are not.

noise_distribution gives each word count ** power, divided by the total so the probabilities sum to 1; the power 0.75 keeps very frequent words such as "the" from dominating the noise. To draw from any distribution, use its running totals (cum): a word owns an interval as long as its probability, so a uniform number between 0 and the last total lands in it with exactly that probability. Redraw whenever you hit avoid, the true context word, so a pair is never both real and fake; the others' chances rescale, which the checker measures over 20,000 draws.
