One attention head makes one kind of lookup, so a layer runs several in parallel, each on its own slice of the vector's width. The results are glued together and mixed by one more matrix. Splitting the width keeps the cost the same: with C = 8 and h = 2, each head handles d_k = 4 numbers per token.

In multi_head_attention, project first: Q, K and V are x times Wq, Wk, Wv, each (C, C). Then split their columns, so head i takes columns i*d_k up to (i+1)*d_k - 1. This is a reshape of the projected vectors, not h separate projections. Run attention in each head (with causal_mask when causal), merge by concatenating columns, and multiply by Wo. split_heads raises ValueError if C is not divisible by h, and merge_heads must undo it exactly.

x = [[1, 2, 3, 4]] (T = 1, C = 4), h = 2, so d_k = 2
split_heads gives [[[1, 2]], [[3, 4]]]; merge_heads gives [[1, 2, 3, 4]] back
