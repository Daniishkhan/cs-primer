A model's size is the number of values in its weights, and for this design it has a closed form that a direct count must match. The forward pass is a chain of steps with known shapes, and a wrong shape shows up on the first run, long before a wrong value does.

One block holds 12*C*C + 9*C weights. The model adds the token table (V rows of C), the position table (T_max rows of C), a final norm (2C) and the head (C by V). count_params walks nested lists and dicts, and must agree with the formula. model_forward adds the first T rows of the position table to the token rows (raise ValueError if T exceeds T_max), applies each block, then the final norm and the head, recording each step in trace. mean_cross_entropy averages -log of the target's probability.

V = 27, C = 16, T_max = 8, 2 layers: 432 + 128 + 2 * 3,216 + 32 + 432 = 7,456
