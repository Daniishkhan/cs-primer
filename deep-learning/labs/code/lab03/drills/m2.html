Attention is a soft dictionary lookup. Each token has a query (what it is looking for), a key (what it offers) and a value (what it hands over). A token scores every key against its query with a dot product, turns the scores into weights that sum to 1, and takes the weighted average of the values.

attention scores all tokens at once with Q K^T, a (T, T) matrix, and divides by sqrt(d_k): a dot product of d_k terms spreads out as d_k grows, and widely spread scores make a softmax nearly one-hot, with almost no gradient. Where mask is True, set the score to -inf before the softmax, so the remaining weights still sum to 1; zeroing weights afterwards does not. causal_mask forbids every key to the right of the query. Use matmul, transpose and softmax_rows.

raw scores 0, 2, 1 with d_k = 2 -> 0, 1.41, 0.71 -> weights 0.14, 0.58, 0.28
mask the last key: 0, 1.41, -inf -> weights 0.20, 0.80, 0.00
