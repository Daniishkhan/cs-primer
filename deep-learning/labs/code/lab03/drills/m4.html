Attention moves information between tokens. The MLP, a small two-layer network, then thinks about each token on its own: it expands the vector from C to 4C numbers, bends each with GELU, and projects back to C. A block wraps both steps in one recipe: normalise a copy of the stream (each token's running vector), run the step, and add its result back.

mlp is gelu(x W1 + b1) W2 + b2; the T rows act as a batch, so nothing crosses between positions. block normalises x with ln1_g and ln1_b, runs multi_head_attention and adds the result to x; then it normalises with ln2_g and ln2_b, runs mlp and adds again (use add). The norm touches only the copy going into a step, never the stream. Residual means add, not replace, which gives a test the checker also runs.

Wo = 0 and W2 = b2 = 0: attention and the MLP add nothing,
so block(x) must return x exactly
