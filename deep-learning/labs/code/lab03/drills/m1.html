Three small functions do the numerical housekeeping of attention. Softmax turns a row of scores into positive weights that sum to 1; layer norm rescales one token's vector to mean 0 and variance 1; GELU is a smooth version of ReLU.

In softmax_rows, subtract the row maximum before math.exp. Masked scores arrive as -inf, and exp(-inf) is exactly 0.0, the weight they need; but a row of all -inf would give nan, so raise ValueError first. layernorm_rows works along each row, never down a column, because one token's output must not depend on another token; divide the variance by C, and keep eps inside the square root. gelu is 0.5 * z * (1 + tanh(sqrt(2 / pi) * (z + 0.044715 * z**3))).

softmax(1, -inf, 3) = 0.119, 0.0, 0.881     gelu(1) = 0.841, gelu(-1) = -0.159
layernorm(1, 2, 3, 4): mean 2.5, variance 1.25 -> -1.342, -0.447, 0.447, 1.342
