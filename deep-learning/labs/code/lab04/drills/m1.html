A number can remember how it was made. If a long calculation ends in one number (the loss), walking back through those records and multiplying each step's local slope gives the gradient of that number for every input: how fast the result changes when that input is nudged.

Each operation returns a new Value holding its inputs and a small function in _back that passes the output's gradient on, times a local slope:

  • sum: 1 for both inputs; product: the other input's value
  • power: k * x ** (k - 1); exp: exp(x); log: 1 / x
  • ReLU: 1 where x > 0, else 0

Add into .grad with +=, never assign: a value used twice receives two contributions. In backward use an explicit stack, not recursion; the checker chains 20,000 operations.

c = a*b + a**2, with a = 2, b = -3
a.grad = b + 2a = -3 + 4 = 1      b.grad = a = 2
