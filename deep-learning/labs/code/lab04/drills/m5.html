A training loss that keeps falling may only mean the model has memorised its examples, so the honest score is the same loss on text it never trained on. To see what the model has learned, generate: draw the next letter at random from its own probabilities, feed it back in, and repeat.

average_loss weights every prediction equally: a name of n letters gives n + 1 predictions (the letters and the end marker), so pool all predictions and divide by their number, not by the number of names. Cut each name to the context length, as sequence_loss does. In sample_name, start from BOS with empty caches, run gpt_step, divide the logits by temperature (below 1 sharpens the odds), turn them into probabilities with plain floats, and draw with sample_index. Subtract the largest logit first: a temperature of 0.01 multiplies logits by 100.
