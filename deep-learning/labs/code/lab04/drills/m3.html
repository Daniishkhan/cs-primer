A language model reads one token (here, a letter) at a time and scores every possible next token. With attention, each position gathers information from the ones before it: its query (what it looks for) is scored against their keys (labels), and the scores weight an average of their values (what they hold).

gpt_step handles one token and returns V logits:

  1. x = wte[token] + wpe[pos]
  2. per layer: rmsnorm, then linear for q, k, v; append k and v to the caches
  3. per head: dot the query slice with each cached key slice, divide by sqrt(d_k), softmax, weight the cached value slices
  4. join heads, apply wo, add to x; the MLP (rmsnorm, w1, ReLU, w2) is added likewise
  5. finish with rmsnorm and head

sequence_loss cuts ids to T + 1 entries, scores each step against the next id with cross_entropy, and returns the mean.

"ana" is ids [0, 1, 14, 1, 0]: four steps, inputs 0, 1, 14, 1,
targets 1, 14, 1, 0; the caches hold 1, 2, 3, 4 entries
