A language model reads one token (here, a letter) at a time and scores every possible next token. Attention lets each position average what the positions up to itself hold (their values), weighted by how well its own query (what it looks for) matches their keys (labels).

gpt_step handles one token and returns V logits:

  1. add the rows wte[token] and wpe[pos] entry by entry to get x
  2. per layer: rmsnorm, then linear for q, k, v; append k and v to the caches
  3. per head i (columns i*d_k up to (i+1)*d_k): dot the query slice with each cached key slice, divide by sqrt(d_k), softmax, weight the cached value slices
  4. join heads, apply wo, add to x; the MLP (rmsnorm, w1, ReLU, w2) likewise
  5. finish with rmsnorm and head

sequence_loss cuts ids to T + 1 entries and averages cross_entropy of each step's logits against the next id.

"ana" is ids [0, 1, 14, 1, 0]: four steps, with inputs 0, 1, 14, 1
after step t the caches hold t + 1 entries
