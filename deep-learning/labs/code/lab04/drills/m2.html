A network's last layer gives one raw score (a logit) per possible next letter. To train it, the scores become probabilities (positive, summing to 1), and the model is charged minus the log of the probability it gave the correct letter: almost nothing if it was sure, a lot if it gave that letter almost none.

All four functions work on lists of Values and use only the Value operations already written, so no new gradient is derived. linear is one dot product per row of W. softmax is exp of each logit divided by the sum of them all; first subtract the largest logit, as a plain float from .data, which changes no probability but stops overflow (the checker tries logits of 1000). rmsnorm multiplies every entry by (mean(x*x) + eps) ** -0.5, so the result has mean square 1. cross_entropy is -log of the target's probability.

softmax(2, 1, 0.1) = 0.659, 0.242, 0.099; target 0 costs -ln 0.659 = 0.417
rmsnorm(3, 4): mean square 12.5, root 3.536, result 0.849, 1.131
