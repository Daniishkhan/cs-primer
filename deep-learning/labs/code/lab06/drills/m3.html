Compute decides how long a run takes; memory decides whether it starts. Training holds model states, which depend only on the parameter count, and activations, the values the forward pass saves for the backward pass, which grow with sequence length s and microbatch b.

States cost 16 bytes per parameter: a 2-byte weight, a 2-byte gradient, a 4-byte master copy and two 4-byte optimiser averages. The activation formula has a part linear in s and a part quadratic in s: the attention score tables. A fused attention kernel ("flash") never stores them. Recomputation ("recompute") keeps only each layer's input and rebuilds the rest during the backward pass, for about a third more compute. fits reserves an overhead for the CUDA context, the GPU software's own working memory. max_microbatch tries 1, 2, 3 and so on until the total no longer fits.

1e9 parameters: 16 bytes each is 16 GB of states, before any activation
