Training is only the first bill: a model that will answer billions of queries pays about 2N FLOPs for every token it generates, a bill that grows with its size. For the same quality, a smaller model trained on more tokens is cheaper over its whole lifetime.

Fix a target loss. The fitted law is E + A / N**alpha + B / D**beta: a floor, a size penalty and a data penalty. For a given N, whatever the target leaves after the floor and the size penalty must come from the data penalty: solve for D, or return None if nothing is left. Lifetime cost is then a function of N alone: huge near the smallest feasible size (D explodes), huge for large N (6ND explodes), with one minimum between, which a ternary search on log N finds.

fit E = 0, A = B = 1, alpha = beta = 0.5, target loss 1.0, N = 4:
size penalty 0.5, so 1 / D**0.5 = 0.5 and D = 4; cost 6*4*4 + 2*4*S = 96 + 8*S
