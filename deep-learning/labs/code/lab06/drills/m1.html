A parameter is one learned number, and nearly all of them sit in matrices, so counting them means multiplying shapes. A language model's weights fall into four groups, attention, the MLP (its feed-forward layers), norms and embeddings, and each group can be counted alone and checked against a published size.

Four ideas need a word. Grouped-query attention shares each key/value head among several query heads, so the key and value matrices are narrower. A gated MLP (SwiGLU) has a third matrix, the gate. A tied output head reuses the input embedding table, so it adds nothing. A mixture of experts keeps several MLPs and a router that picks top_k of them per token, so stored and active counts differ (active=True).
