A FLOP is one floating-point operation, an addition or a multiplication, and a matrix product of (m, k) by (k, n) costs 2mkn of them. So a layer costs 2 FLOPs per weight per token going forward and 4 more going back, and training costs about 6ND FLOPs for N weights and D tokens.

matmul_weights counts only weights that sit in matrix products: not norms or biases, and not the input embedding (a lookup). The output head counts, and so do only the top_k experts used. Attention scores are products with no weights; they add 12*L*C*T per token. Time is FLOPs divided by the speed you really get: peak times MFU (model FLOPs utilisation, the fraction of peak a run delivers, often 0.3 to 0.5). GPU-hours do not depend on how many GPUs share the work.

N = 1e9, D = 2e10: 6ND = 1.2e20 FLOPs
peak 1e15 FLOP/s at MFU 0.4: 1.2e20 / 4e14 = 3e5 s = 83.3 GPU-hours
