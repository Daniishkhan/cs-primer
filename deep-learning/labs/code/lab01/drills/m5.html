Backpropagation only computes gradients; learning is the update that uses them. A gradient points uphill on the loss, so moving every parameter a small step against it goes downhill. The step is scaled by the learning rate, lr. Using the whole training set for each step is full-batch gradient descent, and one pass over it is an epoch.

sgd_step must write through indices, params["W1"][i][j] -= ..., because a loop variable holding a float is only a copy; the biases are flat lists. predict takes the largest logit in each row: softmax would not change which one that is, so skip it. In train, record the loss before each update, so entry 0 belongs to the starting weights. If the loss rises even with a small lr, suspect the sign of the update.

p = 1.0, dp = 0.5, lr = 0.1: p becomes 1.0 - 0.1 * 0.5 = 0.95
