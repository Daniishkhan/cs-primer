Backpropagation sends the loss's gradient backwards through the network, one layer at a time, reusing the values saved in the cache. One rule organises it: a gradient always has the same shape as the thing it is the gradient of, and that shape usually forces the formula.

The docstring lists the steps; shapes show why they are right. With a batch of B, a1 is (B, H) and dz2 is (B, K), so the only product with the (H, K) shape of W2 is a1 transposed times dz2. The gradient passed to the layer below uses W2 transposed for the same reason. A unit that ReLU clipped has slope 0, so it receives no gradient from that example. Reuse transpose, matmul, hadamard and col_sums, and test yourself as the checker does: nudge one weight by 1e-6 each way and compare the change in loss with your gradient.
