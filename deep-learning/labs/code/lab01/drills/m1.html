A network layer is a matrix product plus a bias, so everything depends on shapes lining up. A matrix here is a list of rows. An (m, n) matrix times an (n, p) matrix gives an (m, p) matrix, whose entry (i, j) is row i of the first dotted with column j of the second.

zip(*B) turns a matrix into its columns, as tuples: transpose must return lists. add_bias copies one vector down every row, and col_sums is its mirror image: what is copied across the rows going forward is summed across the rows going backward. hadamard multiplies entry by entry. Raise ValueError when sizes disagree, and build a fresh list for every row: [[0.0] * n] * m makes m references to one row, and the checker compares your arguments with copies to catch mutation.

(1, 3) @ (3, 2) is (1, 2): [[1, 2, 3]] @ [[1, 0], [0, 1], [1, -1]] = [[4, -1]]
col_sums(add_bias([[1, 2], [3, 4]], [10, 20])) = [24, 46] = [4, 6] + 2*[10, 20]
