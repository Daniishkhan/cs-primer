A network ends in raw scores (logits), one per class. Softmax turns them into probabilities, and the loss is minus the log of the probability given to the true class. Its gradient for each logit is the predicted probability minus the truth (1 for the true class, 0 for the others).

softmax_rows works one row at a time; subtract the row's largest logit before exp, which changes no probability but stops overflow. cross_entropy averages over the batch, so every example carries 1/B of the loss and softmax_ce_grad must divide by B, the line most often forgotten. relu_grad returns a matrix of 1.0 and 0.0, ready for hadamard in the backward pass. Copy P before you subtract; never edit it.

P = [[0.5, 0.5], [0.25, 0.75]], y = [0, 0]: loss = (0.693 + 1.386) / 2 = 1.040
gradient = [[-0.25, 0.25], [-0.375, 0.375]]: halved because B = 2; rows sum to 0
