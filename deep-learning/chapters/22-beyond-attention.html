Beyond Attention

Attention reads every earlier token, so its cost and its memory grow with the length of the text. Linear attention and state-space models replace that growing cache with a state of fixed size. This chapter shows how they work, what the fixed size costs in recall, and why current designs mix the two.

Why this matters

Chapter 19 made attention cheaper without changing what it does. This chapter asks whether the quadratic cost can be removed by changing what is computed, and the honest answer is "partly, with a price". You will meet these names in model announcements (Mamba, RWKV, linear attention, DeltaNet, hybrid models), and the claims attached to them are usually about long-context speed and memory. After this chapter you can say what such a layer stores, why that is cheap, which kinds of task it handles badly, and why most deployed designs that use it keep some attention layers.

The cost we are trying to remove

Softmax attention (chapter 9) lets a new token look at every earlier token. That is its strength: a fact placed anywhere in the context can be retrieved exactly. It is also the cost. Training and prefill do work that grows with T², and generation must store, and re-read at each step, a cache that grows with T (chapter 19). Chapter 19's tricks reduce the constants and fix the memory traffic, but the growth with T stays.

The alternative family compresses the past into a state of fixed size. Each new token updates the state, and the output is read from it. Work per token and memory per sequence are then constant, however long the text. This is the idea of the recurrent networks of chapter 8, which were abandoned because they trained slowly and forgot. The modern versions are designed to fix exactly those two problems.

Linear attention

Start from attention for one query: ot = ∑i≤t softmax-weight(qt, ki) vi. The softmax of the dot product is what forces the model to compare the query with every key before it can normalise. Katharopoulos et al. (2020, "Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention") replace the exponential similarity by a product of feature maps, sim(q, k) = φ(q) · φ(k), with φ positive (they use elu(x) + 1). Then

ot = ∑i≤t (φ(qt) · φ(ki)) vi / ∑i≤t φ(qt) · φ(ki) = φ(qt)T St / φ(qt)T zt

where St = ∑i≤t φ(ki) viT is a d × d matrix and zt = ∑i≤t φ(ki) a vector of length d. The step that matters is moving φ(qt) outside the sum, which the missing softmax allows by the associativity of matrix products. S and z can be updated one token at a time: St = St−1 + φ(kt) vtT. The script checks that the parallel form (a T × T matrix, as in training) and the recurrent form (a fixed state, as in generation) give the same outputs.

# Linear attention: the same layer computed in parallel (like attention) and as a recurrence with a fixed-size state.
import numpy as np
rng = np.random.default_rng(0)
T, d = 12, 8
Q, K, V = (rng.normal(size=(T, d)) for _ in range(3))
phi = lambda x: np.where(x > 0, x + 1, np.exp(x))               # elu(x) + 1: a positive feature map, as in Katharopoulos et al. (2020)
Qf, Kf = phi(Q), phi(K)

# Parallel form: a T x T matrix of non-negative weights, causal, normalised to sum to 1 (this is O(T^2) again).
A = np.tril(Qf @ Kf.T); A = A / A.sum(1, keepdims=True)
par = A @ V

# Recurrent form: keep S = sum of outer(k, v) and z = sum of k. Constant size, however long the sequence.
S, z, out = np.zeros((d, d)), np.zeros(d), []
for t in range(T):
    S += np.outer(Kf[t], V[t]); z += Kf[t]                      # write: add this token's key-value pair into the state
    out.append((Qf[t] @ S) / (Qf[t] @ z))                       # read: query the state
print("max |parallel - recurrent| =", np.abs(par - np.array(out)).max())
print(f"state after {T} tokens: S {S.shape} + z {z.shape} = {S.size + z.size} numbers; it stays that size at {T} million tokens")
print(f"a KV cache for the same head holds {2 * T * d} numbers now, and grows by {2 * d} per token")
max |parallel - recurrent| = 4.440892098500626e-16
state after 12 tokens: S (8, 8) + z (8,) = 72 numbers; it stays that size at 12 million tokens
a KV cache for the same head holds 192 numbers now, and grows by 16 per token

The two agree to rounding (about 4 × 10−16). So the layer can be trained in parallel like attention and run as a recurrence at generation time, with a state of d² + d numbers per head in place of a cache that grows by 2d per token. The authors' abstract reports speed-ups of up to 4,000 times for autoregressive prediction of very long sequences, a comparison with softmax attention without a cache optimised as in chapter 19, so read it as an upper bound for that setting.

State-space models and Mamba

A second line comes from control theory. A state-space model (SSM) keeps a hidden state h and updates it linearly: ht = A ht−1 + B xt, with output yt = C ht. If A is diagonal with entries between 0 and 1, each state channel is a memory that fades at its own rate. S4 (Gu, Goel and Ré, 2021, "Efficiently Modeling Long Sequences with Structured State Spaces") made this practical for long sequences. Because A, B and C are fixed, the whole layer is also a convolution of the input with a kernel kj = C Aj B, and a convolution can be computed in parallel during training. Part 1 of the script below checks that the recurrence and the convolution agree.

The weakness of a fixed A is that the layer treats every token the same way: it forgets at the same rate whatever the content. Mamba (Gu and Dao, 2023, "Mamba: Linear-Time Sequence Modeling with Selective State Spaces") makes the parameters depend on the current input, so the layer can decide, token by token, what to write into the state and what to ignore. This is called selectivity. It breaks the convolution form (the kernel would change with the input), so Mamba computes the recurrence with a hardware-aware parallel scan instead. Its abstract reports fast inference, "5 times higher throughput than Transformers", linear scaling in sequence length, and that Mamba-3B outperforms same-size Transformers and matches ones twice its size; these are the authors' claims on their benchmarks. Part 2 of the script shows why selectivity matters, with a gate that depends on the input.

# A state-space layer as a recurrence, as a convolution, and with an input-dependent ("selective") gate.
import numpy as np
rng = np.random.default_rng(0)

# 1. Linear time-invariant SSM with a diagonal state: h_t = a * h_{t-1} + b * x_t, y_t = c . h_t
T, N = 16, 4
a = np.array([0.9, 0.7, 0.5, 0.2]); b = rng.normal(size=N); c = rng.normal(size=N); x = rng.normal(size=T)
h, y_rec = np.zeros(N), []
for t in range(T):
    h = a * h + b * x[t]; y_rec.append(c @ h)                   # constant work and memory per token
kernel = np.array([np.sum(c * a ** j * b) for j in range(T)])   # the same layer as a convolution with kernel k_j = c . (a^j * b)
y_conv = np.array([sum(kernel[j] * x[t - j] for j in range(t + 1)) for t in range(T)])
print("max |recurrence - convolution| =", np.abs(np.array(y_rec) - y_conv).max())

# 2. Why selectivity: remember one flagged value among noise. Fixed decay versus an input-dependent gate.
def run(selective, T=200):
    err = []
    for _ in range(300):
        vals = rng.normal(size=T); flag = np.zeros(T); pos = rng.integers(5, T - 50); flag[pos] = 1
        h = 0.0
        for t in range(T):
            if selective:
                g = 1 / (1 + np.exp(-20 * (flag[t] - 0.5)))      # gate computed from the current input: ~1 on the flag, ~0 elsewhere
                h = (1 - g) * h + g * vals[t]                    # overwrite on the flag, otherwise keep the state unchanged
            else:
                h = 0.95 * h + 0.05 * vals[t]                    # fixed exponential decay: every token is blended in
        err.append(abs(h - vals[pos]))
    return np.mean(err)
print(f"recall of the flagged value after 200 tokens: mean error fixed decay {run(False):.3f}, selective gate {run(True):.3f}")
max |recurrence - convolution| = 4.440892098500626e-16
recall of the flagged value after 200 tokens: mean error fixed decay 0.762, selective gate 0.004

With a fixed decay of 0.95 each step, the flagged value is blended with at least 50 later tokens of noise and recalled with an average error of 0.76 (the values have standard deviation 1). With a gate computed from the input, the layer overwrites its state on the flag and leaves it alone otherwise, and the error is 0.004. Real Mamba layers have many channels and learned gates, but this is the principle.

The two lines then merged in theory. Dao and Gu (2024, "Transformers are SSMs: Generalized Models and Efficient Algorithms Through Structured State Space Duality") show that Mamba-style layers and a form of attention are two views of the same structured matrices; their abstract says the resulting Mamba-2 layer is 2 to 8 times faster than Mamba's core and stays competitive on language modelling.

What a fixed state cannot do

Compression is never free. A state of d² numbers cannot hold more than about d² independent facts, and in the linear-attention form the pairs interfere with each other, because they are summed into the same matrix. The next script stores n random key-value pairs in a 32 × 32 state and asks for each value back, then does the same with a cache that keeps every pair.

# What a fixed-size state can hold: store n key-value pairs, then ask for each value back.
import numpy as np
rng = np.random.default_rng(0)
d = 32                                                          # key and value width, so the state is a d x d matrix (1,024 numbers)

def unit(X): return X / np.linalg.norm(X, axis=1, keepdims=True)

def recall(n):
    K, V = unit(rng.normal(size=(n, d))), unit(rng.normal(size=(n, d)))
    S = sum(np.outer(v, k) for k, v in zip(K, V))               # linear attention: add every pair into one d x d state
    state = np.mean(np.argmax(unit(K @ S.T) @ V.T, axis=1) == np.arange(n))   # read each key back; is it the right value?
    w = np.exp(20 * K @ K.T); w /= w.sum(1, keepdims=True)      # softmax attention over a cache that stores every pair
    cache = np.mean(np.argmax(unit(w @ V) @ V.T, axis=1) == np.arange(n))
    return state, cache

print(f"{'pairs stored':>12} {'fixed state':>12} {'KV cache':>10}")
for n in (4, 8, 16, 32, 64, 128, 256):
    r = np.array([recall(n) for _ in range(20)]).mean(0)
    print(f"{n:>12} {r[0]:>12.0%} {r[1]:>10.0%}")

# Overwriting: replace the values stored under 8 keys. The plain additive state keeps the old value too;
# the delta rule first subtracts what the state predicts for the key, so the new value replaces the old one.
K = unit(rng.normal(size=(8, d))); old, new = unit(rng.normal(size=(8, d))), unit(rng.normal(size=(8, d)))
cos = lambda a, b: np.mean(np.sum(unit(a) * unit(b), axis=1))
S_add = sum(np.outer(v, k) for k, v in zip(K, old)) + sum(np.outer(v, k) for k, v in zip(K, new))
S_del = np.zeros((d, d))
for vals in (old, new):
    for k, v in zip(K, vals): S_del += np.outer(v - S_del @ k, k)
for name, S in (("additive", S_add), ("delta rule", S_del)):
    read = K @ S.T
    print(f"{name:<11} reads back: similarity to new value {cos(read, new):5.2f}, to old value {cos(read, old):5.2f}")
pairs stored  fixed state   KV cache
           4         100%       100%
           8         100%       100%
          16         100%       100%
          32          98%       100%
          64          83%       100%
         128          45%       100%
         256          16%       100%
additive    reads back: similarity to new value  0.65, to old value  0.64
delta rule  reads back: similarity to new value  0.93, to old value  0.05

The second half of the output shows one such richer rule. The additive state cannot replace a stored value: asked for a key that was overwritten, it returns about equal parts old and new. The delta rule, which first subtracts what the state currently predicts for the key and then writes the difference, replaces it (similarity 0.93 to the new value and 0.05 to the old). This idea comes from fast-weight programmers (Schlag, Irie and Schmidhuber, 2021) and is the core of DeltaNet-style layers. It improves the use of the state but does not change its size.

This limit has been measured on trained models. Jelassi et al. (2024, "Repeat After Me: Transformers are Better than State Space Models at Copying") prove that a model with a fixed-size state cannot copy long arbitrary strings the way a two-layer Transformer can, and report that pre-trained Transformers far outperform pre-trained state-space models at copying and retrieving information from the context. Their abstract is explicit that the state-space models remain promising for efficiency, so the trade is efficiency against exact recall.

Common misconception

"A state-space model with a million-token context remembers a million tokens." It has a million tokens of input and a state of a few megabytes. What is retained is whatever the learned gates judged worth keeping. For a task like "what was the invoice number on page 3?", where the needed fact looks unimportant until you are asked, a model that keeps the exact text and searches it (attention, or retrieval, A5 chapter 13) has an advantage that no gate can fully replace.

Hybrids: a few attention layers among many recurrent ones

If recurrent layers are cheap but forgetful and attention is exact but costly, the sensible design uses both. A hybrid model stacks mostly recurrent layers with an attention layer every few blocks. The attention layers give exact lookup; the recurrent layers carry the bulk of the computation at constant memory. Jamba (Lieber et al., 2024) is a published example, interleaving Transformer and Mamba layers with mixture-of-experts (chapter 20) in some of them; its abstract reports strong results for contexts up to 256K tokens and a configuration that fits in a single 80 GB GPU with a small memory footprint compared with vanilla Transformers. The memory script shows why, using the chapter 16 shape and an assumed hybrid with one attention layer in every eight.

# Memory a model must keep per sequence as the context grows: attention KV cache versus a recurrent state.
L, KV, d_k, C = 32, 8, 128, 4096                                # Llama 3 8B shape (chapter 16)
kv_tok = 2 * L * KV * d_k * 2                                   # bytes per token, bf16 (chapter 19)
state_layer = 2 * C * 16 * 4                                    # ASSUMED Mamba-style layer: d_inner = 2C, state size 16, fp32
hyb_attn = L // 8                                               # ASSUMED hybrid: 1 attention layer in every 8, the rest recurrent
print(f"{'context':>9} {'all attention':>14} {'all recurrent':>14} {'hybrid (1 in 8)':>16}")
for ctx in (8_192, 131_072, 1_048_576):
    attn = kv_tok * ctx
    rec = state_layer * L
    hyb = kv_tok * ctx * hyb_attn // L + state_layer * (L - hyb_attn)
    f = lambda b: f"{b/2**30:.2f} GiB" if b >= 2**30 else f"{b/2**20:.0f} MiB"
    print(f"{ctx:>9,} {f(attn):>14} {f(rec):>14} {f(hyb):>16}")
  context  all attention  all recurrent  hybrid (1 in 8)
    8,192       1.00 GiB         16 MiB          142 MiB
  131,072      16.00 GiB         16 MiB         2.01 GiB
1,048,576     128.00 GiB         16 MiB        16.01 GiB

The recurrent state is a fixed 16 MiB at every length, under assumptions about the layer stated in the code. The attention cache is 16 GiB at 128K tokens, and a hybrid with one attention layer in eight needs about an eighth of that. The per-sequence saving translates into more concurrent sequences per GPU (A3 chapter 18). It also shows what the hybrid keeps: its cache still grows with length, only more slowly.

State of play, October 2026

Transformers with attention remain the default for frontier language models as far as published reports show, with the efficiency techniques of chapter 19 and, often, mixture of experts. Hybrids have moved from research to released models: Alibaba's Qwen3-Next-80B-A3B is documented in its model card as a 3:1 mix of Gated DeltaNet (a linear-attention layer with a delta rule and a forgetting gate; Yang, Kautz and Hatamizadeh, 2024) and gated attention layers, 48 layers in all. I read that through search-result summaries of the card, not the card itself, so confirm it before citing. Whether pure state-space models will catch up on exact-recall tasks, or hybrids remain the answer, is unsettled, and the benchmarks used to argue it change often. Treat any ratio or name here as a snapshot.

Systems connection

The trade here is the oldest one in storage systems: keep everything and search it, or keep a summary and answer fast. A KV cache is a log with random access; a recurrent state is a materialised aggregate, as in a streaming job that maintains running counts instead of the raw events. The aggregate is cheap to keep and to serve, and it cannot answer a question its fold function did not anticipate. Constant-size state also helps serving: a session's state can be stored, moved and resumed cheaply, where a long cache has to be paged (A3 chapter 20).

Key takeaways

  • Linear attention drops the softmax so the sum over earlier tokens can be kept as a fixed-size state: St = St−1 + φ(kt) vtT. The same layer trains in parallel and generates as a recurrence.
  • State-space models are linear recurrences that also act as convolutions; Mamba makes them selective, so what is written depends on the input.
  • The fixed state costs constant time and memory per token, and it limits exact recall: it cannot store more than its size, and a trained comparison shows Transformers copying and retrieving much better.
  • The delta rule lets a state overwrite old values and uses it better, but does not enlarge it.
  • Hybrids use mostly recurrent layers and a few attention layers, shrinking the cache by roughly the fraction of attention layers.

Check your understanding

What change lets linear attention be computed as a recurrence with a fixed-size state?

  1. Using fewer heads, so there is less to store
  2. Replacing the softmax of the dot product by a product of feature maps, so that the sum over earlier tokens can be accumulated in a d × d matrix
  3. Applying a window, so old tokens are ignored
  4. Storing the keys and values in lower precision
With sim(q, k) = φ(q) · φ(k), φ(q) factors out of the sum and the remaining sum of φ(k) vT terms can be updated token by token. Fewer heads and lower precision shrink a cache but leave it growing. A window caps the cache at W entries but is a different mechanism that discards tokens instead of summarising them.

A fixed 32 × 32 additive state is asked to hold 256 random key-value pairs. What should you expect?

  1. Perfect recall, since the state is trained
  2. Perfect recall, because the keys are different
  3. Recall limited only by the output precision
  4. Poor recall, because the pairs are summed into the same 1,024 numbers and interfere
The script measured 16% at 256 pairs against 100% for a cache that stores them all. A state of d² numbers has limited capacity, and in an additive state the pairs overlap. Different keys do not prevent interference when there are far more than d of them, and precision is not the limiting factor.

What does Mamba's "selectivity" add to a time-invariant state-space layer?

  1. The update of the state depends on the current input, so the layer can choose what to remember and what to ignore
  2. The state grows with the sequence, so nothing is forgotten
  3. The layer uses softmax attention over the state
  4. The layer can be computed as a single fixed convolution
An input-dependent gate lets the layer keep or overwrite the state according to content, as the flagged-value experiment showed (error 0.004 against 0.76). The state stays fixed size. Because the dynamics now vary with the input, the single-convolution form no longer applies, which is why a parallel scan is used.

A team wants 1M-token contexts with exact lookup of facts anywhere in the text. Which design fits best?

  1. A pure state-space model, because its memory does not grow
  2. Linear attention with a smaller feature map
  3. A hybrid with some attention layers, perhaps with retrieval, accepting a cache that still grows but more slowly
  4. A sliding window of 4,096 tokens on every layer
Exact lookup needs something that keeps the text: attention layers, or a retrieval step. A hybrid keeps a few such layers and puts most of the work in cheap recurrent ones. A pure fixed-state model is the one most prone to dropping facts, and a window discards everything older than itself.
